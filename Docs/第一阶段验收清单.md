# 第一阶段 试玩说明与验收清单

## 启动

在Unity中打开项目的 `Assets/StageOne/Scenes/StageOne.unity`，点击Play。当前画面标题为“界限之间”，是演练阶段的临时标题。

当前未提供已验证的Windows试玩构建。负责人可使用 **GameMake → Build Stage One Windows** 自行打包，构建后运行 **BetweenTheVeils.exe**，并保留其相邻数据目录。代码已经通过一次Unity编译，本清单中的运行检查尚待执行。

## 这一版可以玩什么

这是四人队伍对三名敌人的战斗演练，包含站位、职业技能、技能形态变化、持续精神状态、濒死与战后理智反馈。你可以完成战斗或撤退，再继续下一场，检查角色状态是否延续。

本版提前加入了**节点生成规则与最小选择页**：开局提供3个房间供选择，每层房间类型与分支数量由玩家理智决定，第10层固定首领。事件、商人、营地、工坊与首领尚无内容，会明确标记“待实现”，点击即跳过并推进到下一层。

本版不含断肢、义肢、图鉴或自动存档。**进入下一层不再自动整备生命**（整备已改由“营地”节点承担，营地尚未实装）；死亡角色不复活。关闭程序后演练进度结束。验收需要满血队伍时，用F3的“整备全队生命”。

## 基本操作

1. 开局先在3个房间中选择一个；点击“普通战斗”进入战斗。
2. 选择当前角色的技能，再点击高亮目标。
3. 点击任意角色，可以查看详情；敌人下方显示下一次攻击预告。
4. 无法使用的技能会显示原因。需要换位时，点击“换位”后选择相邻队员。
5. “稳定心神”增加15点个人理智，“直视深渊”减少15点，每场分别限用两次。
6. 医师的包扎可以救治濒死队友，护卫可以掩护，弩手与护卫的部分技能可以打断。
7. F1打开说明，F3打开验收工具，Esc关闭面板或取消目标选择。

## 建议验收顺序

### A 完成正常战斗

- [ ] 点击“新开演练”，确认出现第1层的3个房间。
- [ ] 点击“普通战斗”进入战斗，完成一次从开始到胜利或撤退的流程。
- [ ] 结算后点击“进入下一层”，确认回到节点选择页且层数增加到2。
- [ ] 技能有合法目标提示，站位不符时显示原因。
- [ ] 敌人行动预告、伤害、治疗与战斗记录能对照理解。

### B 检查理智区间

- [ ] F3选择“理智50”，确认技术与原始形态概率均为0，基础形态为100%。
- [ ] F3选择“理智15”，确认仅原始形态有概率出现，技术形态为0。
- [ ] F3选择“理智85”，确认仅技术扩展有概率出现，原始形态为0。
- [ ] 注意：特殊形态不是必出。多进行几次角色行动，可观察抽取结果。

### C 检查持续状态与个人理智

- [ ] 点击一名存活队员查看详情，F3给予“凝神”或“躁动”。
- [ ] 在工具中将该队员理智设为50，确认持续状态仍在，但特殊形态概率为0。
- [ ] 点击“结束当前演练”，再点击“进入下一层”，在新一层点击“普通战斗”进入下一场，确认该队员的理智与持续状态仍保留。
- [ ] “治疗状态”是开发工具，仅用于验证状态清除；正式营地治疗在第二阶段加入。

### D 检查战后反馈

- [ ] F3点击“反馈−2.5”，查看四名队员变化−20、−10、0、+10。
- [ ] 结算显示平均变化−5，乘0.5后玩家理智从50变为47.5。
- [ ] 点击“进入下一层”，玩家理智不会再次扣除2.5。

### E 检查濒死

- [ ] F3点击“濒死演练”，确认护卫0生命但仍存活。
- [ ] 等医师行动后用包扎治疗护卫，确认生命恢复后脱离濒死。
- [ ] 处于濒死时再次受到攻击或流血可能死亡；死亡队员在后续战斗中不复活。

### F 检查显示与手感

- [ ] 中文没有缺字，技能、血量、理智、房间名称与预告易于辨认。
- [ ] 缩放窗口后，按钮仍能准确点击，重要内容没有被遮挡。
- [ ] 提出需要调整的文字、布局、操作或战斗规则。

### G 检查节点生成与理智影响

- [ ] 新开一局时第一层固定出现3个房间；每个房间卡片下方写明用途，标记“待实现”的房间显示“点击跳过”。
- [ ] 页面左侧列出本层可能出现的6种房间概率，随玩家理智变化。
- [ ] F3点击“跳到首领层”，确认第10层只有一个“首领”房间；点击它本局结束，出现“本局结束”面板与“新开一局”。
- [ ] 用F3的“理智15”与“理智85”分别新开队伍，对比节点页：理智15时分支出现在1–2个为主，普通战斗与精英战斗占比更高；理智85时分支以2–3个为主，商人、营地与工坊占比更高。
- [ ] 反复开关F1/F3返回节点页，确认本层房间的名称与顺序完全没有变化（已经展示的房间不会重抽）。
- [ ] 点击一个“待实现”的房间，确认直接进入下一层，战斗计数不增加。
- [ ] 用F3的“跳过本层”推进到第9层，确认每层都至少有一个可进入的“普通战斗”。
