# 复古屏幕扫描扭曲

地图理智条和战斗理智条统一为淡灰色 #CDCDCD。

`RetroScreenNoise` 让横贯屏幕的细扫描线从顶部向下移动，粗细、速度与左右偏移随机。地图和技能介绍屏各最多显示 1 条；越过底部后空出 3～5 秒，再从顶部重新进入。地图宽度保持 0.6～1.2px、速度 260～420px/s；技能介绍屏宽度保持 0.6～1px、速度 110～180px/s。尺寸和速度按 UI 参考像素计。

效果在当前项目的 Built-in 渲染管线中，通过 GrabPass 读取已绘制的屏幕，局部偏移真实文字和图案。灰绿色细线与扭曲共用同一个中心、宽度和下落速度。透明度保持 14%～20%，遇到明亮文字时覆盖降至原强度的 12%；地图局部位移提高至 2～4 像素，技能介绍屏为 1.5～3 像素，只作用于线条经过的窄区域。无宽幅光晕，边缘抗锯齿，不接收点击。使用独立 System.Random，不消耗地图或战斗的随机序列；动画和出现间隔使用非游戏时间，暂停游戏时仍继续变化，隐藏页面时停止。

可在预制体的 `Retro Signal Noise - 屏幕干扰` 组件中调整扫描带数量、粗细、下落速度和位移幅度。`GameMake > UI > Apply Retro Screen Effects` 可重新应用默认效果；地图和战斗重建器也会保留效果。主场景、地图预览和战斗预览通过预制体自动使用这套效果。

验证结果和截图：`D:/GameMake/交付/屏幕扫描扭曲/`。验证包含渲染前后的像素对比，确认文字实际发生位移。
