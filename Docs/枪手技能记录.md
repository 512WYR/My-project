## 高理智特殊技能：贯穿弹

| 项目 | 已确认设定 |
| --- | --- |
| 技能名称 | 贯穿弹 |
| 使用限制 | 每场战斗累计最多使用3次，与阻断射击分别计数 |
| 解锁条件 | 枪手处于高理智状态 |
| 施放站位 | 枪手处于己方4号位 |
| 可选主目标 | 敌方1、2、3、4号位中的一名敌人 |
| 主目标伤害 | 100%基础伤害 |
| 贯穿范围 | 同时攻击主目标后面的最多两名敌人 |
| 伤害递减 | 沿贯穿方向，伤害逐个降低25% |
| 打断效果 | 打断主目标的行动 |
| 打断作用范围 | 仅主目标 |
| 目标数量 | 最多3名敌人：1名主目标及其后方最多2名敌人；后方不足两名时仅攻击实际存在的目标 |

伤害递减暂按每次减少25%基础伤害理解，即主目标100%、后方第一名75%、后方第二名50%基础伤害；此计算口径为暂定解释，待用户确认。

高理智阈值、行动消耗、各目标的命中判定方式、目标已经行动或具备多次行动时的打断处理及其他未指定参数待定。

## 战斗内使用次数统计

阻断射击与贯穿弹的使用次数分别按单场战斗累计，进入下一场战斗时重置。同一场战斗中理智状态变化或再次解锁技能，不刷新已消耗的次数。

## 实现取值（暂定）

以下数值逐条对应上文「待定」，全部集中在 `Assets/StageOne/Editor/StageOneBuild.cs` 的 `Gunner()` 一处。
通用口径与战士文档相同：伤害 = 攻击力 × 倍率向上取整、暴击 ×1.5、形态门控为理智 > 70 / < 30 且权重 0.2 / 0.6 / 0.2。
技能命中率的写法是**相对基准 0.9 的绝对值**，所以「命中率降低到 0.75」就是最终命中 0.75（健康状态下）。

| 技能 | 待定项 | 暂定取值 |
| --- | --- | --- |
| 指定射击 | 伤害数值 | 攻击力 × 1.0（约 10 点） |
| 指定射击 | 使用次数 | 不限次 |
| 阻断射击 | 伤害数值 | 攻击力 × 0.7（约 7 点） |
| 阻断射击 | 使用次数 | 每场 2 次，与贯穿弹分别计数（已按文档实现） |
| 阻断射击 | 目标已经行动时的处理 | 打断只记 1 次：目标本回合尚未行动则跳过本回合行动；若本回合已经行动过，这一次打断顺延到它的下个回合生效 |
| 阻断射击 | 多次行动敌人的打断范围 | 打断一次只跳过 1 个回合的行动，不整场封锁 |
| 军备补充 | 命中率提升幅度 | 全队命中 +0.2（绝对值，即 0.9 → 1.0 上限截断） |
| 军备补充 | 增益持续时间 | 本回合结束（回合开始时统一清除） |
| 军备补充 | 增益叠加规则 | 取较高值，不叠乘；重复施放不累加 |
| 军备补充 | 使用次数 | 不限次 |
| 拖拽射击 | 拖拽后其他敌人如何让位 | 被拖拽目标前方的敌人各后退 1 位，相对次序不变；目标已在 1 号位时不再移动 |
| 拖拽射击 | 位移抗性与免疫交互 | 暂时没有位移抗性；目标闪避掉这次攻击则完全不触发拖拽；目标处于失衡状态时位移必定命中（不会失手、也不会被闪避） |
| 拖拽射击 | 使用次数 | 不限次 |
| 指定射击·散乱 | 命中率降低幅度 | 命中率降到 0.75（降低 0.15） |
| 指定射击·散乱 | 125% 与 50% 的计算基准 | 主目标 攻击力 × 1.25；每名溅射目标再按主目标伤害的 50% 计，最多 2 名（取最近的，同距取更靠前的） |
| 指定射击·散乱 | 溅射的命中判定 | 与主目标共用同一次命中判定：主目标命中则溅射一并结算，未命中则全部落空 |
| 贯穿弹 | 伤害递减口径 | 每退一位减 0.25 倍基础伤害：主目标 100%、后方第一名 75%、后方第二名 50%（与文档的暂定解释一致） |
| 贯穿弹 | 各目标的命中判定 | 与主目标共用同一次命中判定 |
| 贯穿弹 | 打断范围 | 只有主目标被打断，后方两名只承受伤害 |
| 贯穿弹 | 使用次数 | 每场 3 次，与阻断射击分别计数（已按文档实现） |
