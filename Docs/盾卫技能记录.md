| --- | --- |

| 施放站位 | 盾卫处于己方1号位或2号位 |
| 作用范围 | 己方1、2、3、4号位的全体角色，包含盾卫自己 |

## 低理智状态：技能变化

| 项目 | 已确认设定 |
| --- | --- |
| 生效条件 | 盾卫处于低理智状态 |
| 失去的技能 | 低理智状态下无法使用技能1、3、4 |
| 技能2变化 | 同时守护盾卫自己和1名其他队友，并在受到攻击或代为承受攻击后触发反击 |
| 技能2施放站位 | 改为仅可在己方1号位或2号位施放 |
| 可选队友位置 | 沿用技能2的范围：己方1、2、3、4号位中的1名其他队友 |
| 持续时间 | 沿用技能2的持续时间：1回合 |
| 守护效果 | 持续期间，被守护队友受到攻击时由盾卫阻挡并代为承受伤害，可多次触发 |
| 反击触发 | 盾卫自身受到攻击，或替被守护队友承受攻击后，由盾卫对攻击者触发反击 |
| 反击次数 | 反击作为增益仅可触发1次，触发后消耗；守护仍持续至原定结束时间，不会因继续承伤而自动再次获得反击 |

此处守护沿用技能2的承伤机制，不自动获得技能4的免除攻击全部效果。低理智阈值、反击伤害、反击范围与其他未指定参数待定。

## 通用反击规则

- 反击作为一种增益（buff）存在，每份反击增益仅可触发1次，触发后消耗。
- 高理智特殊技能中，各角色的反击增益分别计算，每人最多触发1次反击。
- 低理智技能2的持续守护和一次性反击分别计算；消耗反击增益不会提前结束守护。

## 实现取值（暂定）

技能 1/2/3 的名称文档写作「待定」，实现时暂定叫**盾击 / 守护 / 壁垒**。其余数值逐条对应上文「待定」，
全部集中在 `Assets/StageOne/Editor/StageOneBuild.cs` 的 `Shield()` 一处。

通用口径与战士文档相同：伤害 = 攻击力 × 倍率向上取整、命中沿用角色 0.9、形态门控为理智 > 70 / < 30 且权重
0.2 / 0.6 / 0.2。防御与精准的增益量都是**绝对值**：防御 +0.2 表示减伤率 +20 个百分点，精准 +0.2 表示命中率 +20 个百分点。

| 技能 | 待定项 | 暂定取值 |
| --- | --- | --- |
| 盾击（技能1） | 名称与伤害 | 名称暂定「盾击」；攻击力 × 0.8（约 8 点） |
| 守护（技能2） | 减伤 | 不额外减伤：伤害原样转移给盾卫，再按盾卫自己的防御与格挡结算 |
| 守护（技能2） | 触发次数 | 1 回合内每次受击都转移，不因触发一次而结束；守护在盾卫下次行动开始时解除 |
| 守护（技能2） | 可守护对象 | 排除盾卫自己，只能选其他三名队友 |
| 壁垒（技能3） | 名称与防御提升幅度 | 名称暂定「壁垒」；全队防御 +0.2（减伤率 +20 个百分点），不能与自身重复叠加，取较高值 |
| 壁垒（技能3） | 增益持续时间 | 本回合结束（回合开始时统一清除），与文档「下回合可正常行动」一致 |
| 格挡（技能4） | 每次赋予的目标数量 | 1 名，仅限己方 1 号位施放时可选 |
| 格挡（技能4） | 持续时间 | 到本回合结束为止；期间未被触发则自动失效 |
| 全队格挡反击 | 反击伤害 | 反击者自己的基础攻击力 × 1.0，不含技能倍率 |
| 全队格挡反击 | 反击攻击范围 | 只打「造成该次攻击的那一名敌人」，单体 |
| 守护·血怒 | 反击伤害与范围 | 同为攻击力 × 1.0、单体 |
| 守护·血怒 | 「同时守护盾卫自己」 | 承伤模型下守护自己无任何可观测效果（盾卫本来就在承受自己的那份攻击），因此实现为「守护 1 名队友 + 盾卫自身获得反击」；盾卫自己被攻击时同样触发这次反击，行为与文档一致 |
| 通用反击 | 次数 | 每份反击增益只触发 1 次，触发后立即消耗；未触发则在本回合结束时失效 |
| 通用反击 | 反击与追击的联动 | 反击造成的伤害同样会触发已持有的追击增益 |
