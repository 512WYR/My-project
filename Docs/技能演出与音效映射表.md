# 技能演出与音效映射表

> 用途：把四个角色的每个技能，逐一对应到「演出立绘」「画面演出」「音效」三件事，作为后续修改 `BattleShowPlan`、`BattlePresentation`、`SfxDirector` 的唯一对照表。
>
> 范围：四个角色的 24 个常规/形态技能 + 5 个义体替换技能。敌人技能仍走 `Show/Attack/<怪物Id>.png`，不在本表内。

## 一、现状诊断

### 1. 枪械开火音效没有接入

`SfxDirector` 目前只有 11 个 cue：`click / turn / defend_up / guard_hit / attack_windup / attack_hit / attack_miss / block / heal / sanity_attack / attack`，没有任何枪声 cue，也没有对应音频文件。

枪手的 `g_shot / g_block_shot / g_resupply / g_grapple / g_primal_shot / g_pierce` 命中时全部走通用 `attack_hit`，所以「枪械开火」听起来和近战命中完全一样。

### 2. 部分技能的演出立绘取不到

`BattleShowPlan.SkillIdFor` 只在 `action` 事件里按 `角色名 · 技能名` 解析技能 Id。但引擎对以下情况不会先发 `action` 事件：

- 未命中：只发 `miss`（`角色 · 技能名 未命中。`），然后直接返回；
- 治疗、驱散、格挡、守护、增益：只发 `heal / buff / guard` 结果事件；
- 吸血扩散的治疗、追击、反击等追加效果。

这些情况下 `BattleShowGroup` 是结果事件合成的，`SkillId` 始终为 null，`BattlePresentation` 只能显示基础立绘。于是「军备补充、群体药雾、驱散疗法、守护、壁垒、格挡、追击」等技能全都看不到自己的演出立绘。

### 3. 义体替换技能没有立绘

`ProstheticSystem.DecorateSkills` 在战斗开始时把技能换成新的 Id：

| 原技能 | 替换后 Id | 现有立绘 |
| --- | --- | --- |
| g_grapple 拖拽射击 | g_whaling_anchor 贯体锚枪 | 无 |
| s_guard 守护 | s_double_guard 双线守护 | 无 |
| s_primal_guard 守护·血怒 | s_double_guard_low 双线守护（低理智） | 无 |
| w_bash 猛击 | w_boiler_shock 锅炉震荡 | 无 |
| m_mist 群体药雾 | m_boiling_mist 沸血药雾 | 无 |

`SkillIdFor` 又只查 `CharacterDefinition` 的三张原始技能表，替换后的名字一个都匹配不到，所以这些技能即使有立绘也不会被取用。

### 4. 立绘资源存在重复

| 文件 | 实际内容 | 问题 |
| --- | --- | --- |
| `g_block_shot.png` = `g_grapple.png` = `g_pierce.png` | 三张完全相同的步枪开火图（MD5 相同） | 阻断射击 / 拖拽射击 / 贯穿弹 看起来是同一个技能 |
| `s_bulwark.png` = `s_phalanx.png` | 完全相同的持盾图（MD5 相同） | 壁垒 / 全队格挡反击 看起来是同一个技能 |

在补画新图之前，先用「色调 + 特效 + 音效 + 位移方式」做区分；补图时只需替换同名 PNG，代码不用再改。

## 二、演出风格代码

### 全局方向规则

- **友方施放**：角色固定在左侧，目标在右侧，攻击方向固定为**左 → 右**。
- **敌方施放**：角色固定在右侧，目标在左侧，攻击方向固定为**右 → 左**。
- 目标按站位排序时，1 号位始终靠近施放方：友方攻击时 1 号位在最左，敌方攻击时 1 号位在最右。
- 受击后退方向始终背离施放方；未命中时角色向前收力。

下表是给每个技能分配的画面表演模板。同一模板下的技能共享基础节奏，再用「色调 / 字印 / 目标反馈」区分。

| 代码 | 风格 | 起手 | 位移 | 命中与目标反馈 | 参考时长 |
| --- | --- | --- | --- | --- | --- |
| R1 | 远程点射 | 身体后仰、枪口抬起 | 原地不冲刺 | 单次枪口火光，目标后仰 70px，伤害数字弹出 | 0.55s |
| R2 | 远程贯穿 | 身体后仰更大、枪身压低 | 原地 | 一条贯穿亮线依次穿过最多 3 个目标，目标按顺序后退 | 0.70s |
| R3 | 远程散射 | 枪口横向扫过 | 原地 | 三次枪口火光，主目标与两侧溅射同时闪白 | 0.65s |
| R4 | 钩索拖拽 | 枪口下压 | 原地 | 枪口伸出锁链/钩索连到目标，目标向前滑 1 位 | 0.75s |
| M1 | 突进斩 | 后撤蓄力 | 冲向目标 | 一道斜向斩击光，目标后退 70px | 0.60s |
| M2 | 重击 | 大幅后撤、武器举高 | 缓慢冲撞 | 屏幕轻震，目标脚下出现冲击环，伤害数字放大 | 0.75s |

## 六、代码落点

后续实现按以下顺序改，避免一次动太多：

1. **`SfxDirector`**
   - `SfxCue` 增加 `Gunshot`（以及可选的 Slash/HeavyHit/Buff/Cleanse/GrappleChain/SteamBurst/Bleed）；
   - `ClipNames`、`CueVolumes` 同步补长度；
   - `Play` 增加可选 `pitch` 参数，用于同一枪声区分手枪/步枪/重枪。

2. **`BattleShowPlan`**
   - 所有可能创建 `BattleShowGroup` 的事件（`miss / heal / guard / buff / damage`）都尝试从事件消息解析技能 Id；
   - 解析不到时再查 `ProstheticSystem.DecorateSkills` 生成的三张形态技能表，覆盖 `g_whaling_anchor / s_double_guard / s_double_guard_low / w_boiler_shock / m_boiling_mist`；
   - `ApplySupport` 的守护日志补上 `" · " + skill.Name`，否则守护类技能没有可解析的技能名。

3. **`BattlePresentation`**
   - 增加 `SkillShowStyle` 分类表：技能 Id → 风格代码、主色、命中音、是否原地、目标后退距离；
   - `PlayGroup` 按风格执行 R1/R2/R3/R4/M1/M2/M3/G1/B1/H1/H2/H3/D1/S1 的分支；
   - 支援/治疗技能也播放对应技能立绘，而不是基础立绘；
   - 枪手技能命中时不再走通用 `AttackHit`，改播 `Gunshot`。

4. **美术资源**
   - 补 `g_block_shot / g_grapple / g_pierce` 三张不同图；
   - 补 `s_bulwark / s_phalanx` 两张不同图；
   - 补 5 张义体替换技能图；未补齐前代码按 4.5 节回退，不会白屏。

5. **音效资源**
   - 至少放入 `gunshot.wav`；其余按 5.2 节可选补充，缺失时 `SfxDirector` 已有「只警告一次并回退」的逻辑。

## 七、实现状态（2026-10-20）

### 已完成

- `SfxDirector`：新增 11 个 cue（`Gunshot / GunshotHeavy / GunshotScatter / GrappleChain / Slash / HeavyHit / ShieldBash / Buff / Cleanse / SteamBurst / Bleed`），`Play` 支持 `pitch`，并加入逐级回退链。缺少文件时只警告一次，不会让整次演出静音。
- `BattleShowPlan`：
  - `damage / heal / miss / dodge / guard / buff` 都会尝试从事件消息解析技能 Id（`NoteSkill`）；
  - 未命中消息的 `" 未命中。"` 后缀会被裁掉，不再被当成技能名的一部分；
  - `ChangeSanity` 的 `"角色 技能：理智 …"` 冒号格式也能解析；
  - 原始三表匹配失败后，再查 `ProstheticSystem.DecorateSkills`，覆盖 5 个义体替换 Id。
- `BattleEngine.ApplySupport`：守护日志补上 `" · " + skill.Name`，守护类技能因此能取到自己的立绘。
- `ActorArt`：5 个义体替换 Id 建立立绘别名回退（新图放入后仍优先直读新 Id）。
- 新增 `Assets/MainGame/Runtime/Battle/SkillPresentation.cs`：29 个技能 Id 的风格表（风格、主色、命中音、额外音、pitch、后撤距离、前摇距离、震屏、额外停留）。
- `BattlePresentation`：
  - 友方 `left → right`、敌方 `right → left`，目标 1 号位始终靠近施放方；
  - 远程技能原地前倾 + 极细射线（普通 3px、贯穿 2px），不再整段冲刺；近战/重击保留突进；
  - 近战、重击、横扫不再绘制斩击光或冲击光，只靠位移、后仰、数字和染色表现；
  - 重击保留更大前摇与屏幕轻震；
  - 角色立绘按结果染色：掉血（含断肢）淡红、治疗淡绿、增益淡蓝；命中后约 0.18s 保持、0.10s 恢复原色，不再覆盖整段演出；未命中、闪避不染色；
  - 支援技能按治疗 / 增益 / 净化区分脉冲幅度与上浮；
  - 起手音、命中音、额外音均由风格表选择；被格挡、未命中时仍优先播放格挡 / 未命中音；
  - 目标后退距离按 `Recoil` 缩放。
- `BattleShowPlanTests`：新增未命中 / 治疗 / 守护 / 增益 / 义体替换 5 个 `SkillId` 解析测试。
