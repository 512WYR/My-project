# 第一阶段 试玩说明与验收清单

## 启动

在Unity中打开项目的 `Assets/StageOne/Scenes/StageOne.unity`，点击Play。当前画面标题为“界限之间”，是演练阶段的临时标题。

当前未提供已验证的Windows试玩构建。负责人可使用 **GameMake → Build Stage One Windows** 自行打包，构建后运行 **BetweenTheVeils.exe**，并保留其相邻数据目录。代码已经通过一次Unity编译，本清单中的运行检查尚待执行。

## 这一版可以玩什么

这是四人队伍对三名敌人的战斗演练，包含站位、职业技能、技能形态变化、持续精神状态、濒死与战后理智反馈。你可以完成战斗或撤退，再继续下一场，检查角色状态是否延续。

本版不含探索、断肢、义肢、图鉴或自动存档。继续演练会整备存活角色的生命；死亡角色不复活。关闭程序后演练进度结束。

## 基本操作

1. 选择当前角色的技能，再点击高亮目标。
2. 点击任意角色，可以查看详情；敌人下方显示下一次攻击预告。
3. 无法使用的技能会显示原因。需要换位时，点击“换位”后选择相邻队员。
4. “稳定心神”增加15点个人理智，“直视深渊”减少15点，每场分别限用两次。
5. 医师的包扎可以救治濒死队友，护卫可以掩护，弩手与护卫的部分技能可以打断。
6. F1打开说明，F3打开验收工具，Esc关闭面板或取消目标选择。

## 建议验收顺序

### A 完成正常战斗

- [ ] 点击“新开演练”，完成一次从开始到胜利或撤退的流程。
- [ ] 技能有合法目标提示，站位不符时显示原因。
- [ ] 敌人行动预告、伤害、治疗与战斗记录能对照理解。

### B 检查理智区间

- [ ] F3选择“理智50”，确认技术与原始形态概率均为0，基础形态为100%。
- [ ] F3选择“理智15”，确认仅原始形态有概率出现，技术形态为0。
- [ ] F3选择“理智85”，确认仅技术扩展有概率出现，原始形态为0。
- [ ] 注意：特殊形态不是必出。多进行几次角色行动，可观察抽取结果。

### C 检查持续状态与个人理智

- [ ] 点击一名存活队员查看详情，F3给予“凝神”或“躁动”。
- [ ] 在工具中将该队员理智设为50，确认持续状态仍在，但特殊形态概率为0。
- [ ] 点击“结束当前演练”并继续下一场，确认该队员的理智与持续状态仍保留。
- [ ] “治疗状态”是开发工具，仅用于验证状态清除；正式营地治疗在第二阶段加入。

### D 检查战后反馈

- [ ] F3点击“反馈−2.5”，查看四名队员变化−20、−10、0、+10。
- [ ] 结算显示平均变化−5，乘0.5后玩家理智从50变为47.5。
- [ ] 点击继续演练，玩家理智不会再次扣除2.5。

### E 检查濒死

- [ ] F3点击“濒死演练”，确认护卫0生命但仍存活。
- [ ] 等医师行动后用包扎治疗护卫，确认生命恢复后脱离濒死。
- [ ] 处于濒死时再次受到攻击或流血可能死亡；死亡队员继续演练时不复活。

### F 检查显示与手感

- [ ] 中文没有缺字，技能、血量、理智与预告易于辨认。
- [ ] 缩放窗口后，按钮仍能准确点击，重要内容没有被遮挡。
- [ ] 提出需要调整的文字、布局、操作或战斗规则。
