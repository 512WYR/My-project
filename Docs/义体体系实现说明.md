# 义体体系实现说明

本文对应《蒸汽朋克义体设计方案》的落地实现，记录 28 件义体的确切 Id、部位、专属限制、战斗效果、替换技能、生命周期、获取入口、界面入口与验证方式。规则代码以 [LimbSystem.cs](../Assets/StageOne/Core/LimbSystem.cs) 与 [ProstheticSystem.cs](../Assets/StageOne/Core/ProstheticSystem.cs) 为准；本文数值与代码同步。

## 1. 结论与边界

- 共 **28 件**：旧版 4 件基础义肢 + 4 套通用系列 × 4 部位（16 件）+ 4 名角色 × 2 件专属（8 件）。
- **任何未装义体的部位都可以安装义体**（完好、重伤、断肢均可）；已装义体的部位不可替换。
- **补给站安装每次 1 矿石且不扣生命；角色面板优先消耗手术包（不扣生命），没有手术包时自由装载，失去 8 点生命。**
- 旧 4 件保留为**无副作用修复件**：只把部位恢复到完好，不提供任何战斗数值。
- 同类百分比**相加**后结算；饰品乘区与义体乘区之间仍然**相乘**。
- 24 件新义体进入现有全部来源：精英掉落、事件、祭坛、补给站商店、调试台、BattleLab。
- 义体随所装部位再次断掉而**销毁**；部位回到断肢状态，需要重新安装。
- 替换技能只替换当前形态技能列表中实际存在的技能 Id，不新增技能槽；义体被销毁后原技能恢复。

## 2. 数据与安装

| 项目 | 规则 |
| --- | --- |
| 安装条件 | 目标部位尚未装义体（完好、重伤、断肢均可）；专属义体还要求 `Silhouette` 匹配 |
| 安装结果 | 写入 `LimbState.Prosthetic` 与 `ProstheticKind`，部位 `Hp = MaxHp`，角色 `Hp` 夹到 `MaxHp` |
| 自由装载 | `LimbSystem.FreeInstall` 在安装后扣除 `FreeInstallHpCost = 8` 点生命，最低留 1 点；补给站安装与手术包装载不扣生命 |
| 部位销毁 | `LimbSystem.Damage` 把部位打空时同时清空义体；原本有义体时立即把角色 `Hp` 夹到新的 `MaxHp` |
| 上限变化 | `ResizeLimbs` 只重算部位上限，保留已装义体；角色 `Hp` 随之夹紧 |
| 库存复制 | `LimbSystem.Clone` 复制 `Kind` 与 `RestrictSilhouette`，所有掉落/商店/事件入口都走它 |
| 默认表 | 28 件放在 `LimbSystem.DefaultProsthetics`；`GameCatalog.asset` 不需要改，旧资产会回落到默认表 |

### 2.1 派生最大生命

```text
ActorState.MaxHp = ceil(Definition.MaxHp × (1 + Σ 已装义体的 MaxHpPercent))，最低 1
```

- `Definition.MaxHp` 仍是基础值；金丝苹果、开局坚韧等仍修改基础值。
- 部位上限仍按基础值创建，不随 +70% 放大。
- 只影响生命上限的义体：`armored_pressure_torso` +70%，`clockwork_compound_eye` −30%。
- 面向玩家的生命上限都读取 `actor.MaxHp`；`AccessorySystem.Attach/Detach` 仍改基础值，Detach 后用 `actor.MaxHp` 夹当前生命。

## 4. 数值公式

所有查询都在 `ProstheticSystem` 中，**纯读取**：不抽随机、不修改角色状态。

| 行为 | 公式与边界 |
| --- | --- |
| 命中 | `EffectiveAccuracy` 加上 `AccuracyOffset`（敌人命中 −0.20，复眼 +0.30），夹 0–1，再取饰品命中地板的最大值 |
| 主动攻击伤害 | `1 + OutgoingDamageBonus`；只作用于主动攻击技能，追击、反击、后续流血不吃 |
| 受到攻击伤害 | `1 + Σ 受伤修正`，最低 0；流血与 `direct` 生命代价跳过 |
| 治疗 | `ceil(原始治疗 × HealReceivedMultiplier)`，夹到 `MaxHp`；`RestoreHp` 是所有治疗入口的唯一实现 |
| 流血 | 只有一个流血槽；新流血取较高值，避免把更强的流血覆盖成 2×2 |
| 反击 | `ceil(攻击力 × CounterRatio × CounterMultiplier)`；复仇飞轮为 ×2 |
| 双线守护代承 | 代承伤害再 ×1.25（`GuardInterceptMultiplier`） |

`OutgoingDamageBonus` 的加成来源：

- 攻城液压臂 +0.60
- 痛觉增幅冠（生命 ≤ 50%）+0.60
- 冷凝镇静颅 −0.25
- 爆燃冲程臂 +1.00
- 喷汽突进腿（本次行动已换位）+0.50
- 陀螺蓄力臂：蓄力 +0.70 / 未蓄力 −0.25
- 棘轮追杀腿（斩劈）+0.70
- 独眼炮术镜（指定射击主目标）+0.80

`DamageTakenFactor` 的修正来源：

- 铸铁潜钟颅 −0.30
- 攻城液压臂 +0.30
- 桩锚支撑足（1 号位）−0.35
- 镂空翼架胸腔：3/4 号位 −0.40，1/2 号位 +0.50
- 喷汽换位后的易伤 +0.40
- 钢索换位后的易伤 +0.25
- 锅炉震荡后的易伤 +0.50

`HealReceivedMultiplier`：装甲承压舱 −0.40、痛觉增幅冠 −0.30、双泵再生胸腔 +0.75，最低 0。
`BleedTakenFactor`：双泵再生胸腔 ×2。

## 5. 替换技能

替换技能是 `Ruin.Core` 内的 `SkillSpec` 常量，由 `ProstheticSystem.DecorateSkills` 交给每场战斗的克隆，不写入资产、不修改共享对象。

| Id | 名称 | 类型 | 施放位 | 目标 | 效果 | 次数 | 矿石 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| `g_whaling_anchor` | 贯体锚枪 | Attack | 己方 3/4 | 敌方 3/4 一名 | 125% 伤害；命中后无概率拖到敌方 1 号位；用后向前一位并与前方队友换位 | 无限 | 1 |
| `s_double_guard` | 双线守护 | Protect | 任意 | 最多 2 名其他队友 | 持续到自身下次行动；可多次触发；代承伤害 +25% | 无限 | 1 |
| `s_double_guard_low` | 双线守护（低理智） | Protect | 己方 1/2 | 最多 2 名其他队友 | 同上；保留一次性反击，不按人数增加 | 无限 | 1 |
| `w_boiler_shock` | 锅炉震荡 | Attack | 己方 1/2 | 敌方 1/2 当前存在者 | 逐目标判定命中，75% 伤害并失衡；使用后自身受伤 +50% | 每场 2 次 | 1 |
| `m_boiling_mist` | 沸血药雾 | Heal | 己方 3/4 | 己方全体含自身 | 恢复攻击力 125% 的生命；治疗后每人获得 2 点流血 2 次 | 无限 | 1 |

补充规则：

- 矿石不足时技能不可用，显示具体原因；**不会自动回退**到原技能。
- 矿石在行动提交时扣除；未命中、拖拽失败都不退还。
- `g_grapple`→`g_whaling_anchor`、`s_guard`→`s_double_guard`、`s_primal_guard`→`s_double_guard_low`、`w_bash`→`w_boiler_shock`、`m_mist`→`m_boiling_mist`。
- 棘轮追杀腿克隆 `w_cleave`（`ActorRanks = 15`、`SelfMove = -2`）；狂医手术镜克隆 `m_blood_heal` / `m_primal_heal`（`BleedChance = 1`）；独眼炮术镜克隆 `g_shot` / `g_primal_shot`（`TargetRanks = 12`）。
- 双线守护通过 `ActionRequest.TargetIds` 选择 1–2 名队友；重复项和非法项会被丢弃，满 2 名自动确认。

## 6. 战斗生命周期

`ActorState.ProstheticBattle`（`ProstheticBattleState`）保存会随回合失效的标记：

```csharp
FreeSwapUsed, GyroCharged, SteamSwapAttackBonus, SteamSwapVulnerable,
SteelWireVulnerable, SteelWireSourceId, BoilerVulnerable,
DoubleGuardActive, RankChangedThisAction
```

每场战斗开始时由 `ResetBattleEffects` 整体重置。

| 时点 | 处理 |
| --- | --- |
| 英雄回合开始 `OnProstheticTurnStart` | 清免费换位、喷汽攻击加成、驻床换位标记、喷汽/锅炉/双线守护易伤；清 `SteelWireSourceId == 本角色` 的钢索易伤；清理使用者已死亡的孤立钢索易伤 |
| 主动攻击结算后 `AfterProstheticAttack` | 爆燃支付 15% 生命（命中与否）；清除陀螺蓄力；锅炉震荡后置自身易伤；红线造成实际伤害后回 10% 生命并 −8 理智；刺吸造成实际伤害后回 15% 生命并给自身 2×2 流血 |
| 行动结束 `OnProstheticActionEnd` | 冷凝 +8 理智；驻床若本次行动未改变站位恢复 5% 生命 |
| 反击 `TryCounter` | 复仇飞轮把反击伤害 ×2；每次实际反击后支付 8% 最大生命，最低留 1，不触发受击/追击 |
| 位移 | 桩锚阻断主动移动；棘轮斩劈多步前移；贯体锚枪的 `PostSelfMove` 要求前方目标格有队友 |
| 免费换位 | 喷汽只换前方相邻队友，钢索可换任意队友；不消耗行动、不调用 `Advance`；每次行动一次 |

生命代价统一走 `PayLife`：`direct + selfInflicted`，不吃防御、守护与其他减伤，先夹到 `Hp - 1`。

## 7. 获取与界面

| 入口 | 行为 |
| --- | --- |
| 精英战斗 | `Encounter.DropProsthetic` 从 28 件中等概率抽一件副本 |
| 事件 / 祭坛 | 复制点使用 `LimbSystem.Clone`，保留 `Kind` 与专属限制 |
| 补给站商店 | 28 件全部上架，售价沿用 `SupplyShop.ProstheticPrice`；描述含专属限制与「任意未装义体的部位都可安装；补给站安装需 1 矿石且不扣生命」 |
| 补给站安装 | 部位（完好、重伤、断肢均可）→ 该部位库存义体 → 安装；扣 1 矿石且不扣生命；重伤页同时保留修复选项；不可安装时显示具体原因 |
| 角色面板 | 任意未装义体的部位可装载；有手术包时优先消耗手术包（不扣生命），没有手术包时自由装载并失去 8 点生命；已装义体不可替换 |
| 调试台 | 按部位循环发放 28 件；安装按钮使用 `InstallBlockedReason`；`DebugGrantAllProsthetics` 发放全部 |
| BattleLab | 配置页按部位列出 28 件，校验断肢与专属限制；默认给足矿石以便测试替换技能 |

HUD 技能详情会显示「耗 X 矿石（当前 Y）」。换位按钮在免费换位可用时也可点击；有多目标待确认技能时优先确认。桩锚角色不能主动换位，但队友可以把他们当作换位目标。

战斗页状态条会为每个已装义体的部位常驻一条「义体·部位」提示（`BattleStatus.AddProsthetics`）：悬停显示义体名称、`ProstheticSpec.Description`、当前部位生命，以及「再次断肢时义体一并损毁」。它只用于说明，不参与结算，也不随回合清除；部位被再次打断、义体销毁后条目立即消失。已装备的饰品同样以「饰品·名称」条目列出描述（`BattleStatus.AddAccessoryHints`），与动态数值条目并存。

### 8.3 手工验收清单

1. 补给站：4 部位 → 任意未装义体的部位 → 子页只列该部位库存；重伤页同时可修复；专属义体在错误角色上禁用；安装扣 1 矿石、不扣生命并恢复部位。
2. 角色面板：完好、重伤、断肢都可装载；有手术包时消耗手术包且不扣生命；没有手术包时自由装载，扣 8 点生命（最低留 1）；已装义体的部位不可替换；专属原因文案正确。
3. 商店：28 件可购买，描述含限制与安装费。
4. 战斗：替换技能名称与描述变化但槽位数量不变；矿石不足灰显；双线守护选 2 人；锅炉震荡打 1、2 号位；贯体锚枪拖拽并前移；沸血药雾给满血角色上流血；喷汽/钢索免费换位不消耗行动；桩锚不能主动移动；义体被打断后技能恢复原版且生命上限回落。
5. 悬停：已装义体的角色脚下出现「义体·部位」，悬停可读到义体名称、效果、部位生命与销毁说明；装备饰品出现「饰品·名称」及原描述；义体被打断后提示消失。
