## 已实现范围

四名角色（战士/盾卫/枪手/奶妈）、站位与速度回合、技能目标选择、区间概率、技能形态、攻击预告、格挡、守护、反击、追击、失衡、打断、拖拽、流血、治疗、濒死、死亡及战后理智反馈。**每回合的行动只有当前形态的技能加一个换位**，没有职业系统、防御、稳定心神、直视深渊与撤退；全队阵亡直接结束本局。

第一阶段是可重复的战斗演练：战斗本身不恢复生命，治疗与部位修复只在补给站提供；个人理智与死亡记录跨战斗保留。三层路线、增益房、补给站、事件与祭坛、肢体与义体已提前落地，宝箱房已上路并会发放一件随机饰品（最终奖励表仍待定）。尚无永久图鉴和磁盘存档；这些属于后续阶段。

义体体系已完整实装：旧 4 件基础义肢只恢复部位功能，另有 4 套通用系列 × 4 部位（16 件）与 4 名角色专属（8 件）共 28 件。新义体只能装在断肢上，会改变最大生命、命中、伤害、治疗、流血、反击或站位；其中 5 个替换技能消耗 1 矿石，喷汽突进腿与钢索巡游腿还提供不消耗行动的免费换位。完整效果与获取入口见 [义体体系实现说明](Docs/义体体系实现说明.md)。

## 操作

- 启动后进入主菜单：**开始游戏** / **设置**（音乐音量，自动保存）/ **退出游戏**。
- 点击技能，再点击高亮目标。点击角色查看理智、技能概率或敌人预告。
- 每次行动或敌人行动都会全屏切入一段短演出：双方立绘对冲，目标头顶显示大号伤害/治疗/暴击/未命中/闪避等结果，并附上理智变化、肢体受伤/断肢、流血与具体 Buff 名称（格挡、反击、追击、防御力+、命中+ 等），播完自动返回战斗页。肢体提示只在部位降到一半（受伤）或归零（断肢）时出现，普通磨损不刷屏；流血在施加时显示具体层数，每次结算单独显示当次流血伤害。群体技能的所有目标同屏同时结算。
- 获得 Buff、出现肢体损伤或装有义体的角色脚下会出现状态条；鼠标悬停可查看每条效果的数值与说明。已装义体的部位常驻「义体·部位」提示，悬停可读到义体名称、完整效果与剩余部位生命；装备的饰品也会以「饰品·名称」列出原描述。战斗页每张位置卡片的立绘底部也常驻同一条状态摘要，悬停同样可用，且不会挡住角色点击。
- 点击头像打开角色面板，处理部位、义体、饰品与药剂。
- 装了喷汽突进腿或钢索巡游腿后，换位按钮会优先进入免费换位；它不消耗本次行动。替换技能会显示矿石消耗，矿石不足时灰显且不会自动回退到原技能。
- Esc：先关闭补给站/角色面板或取消目标选择；没有其他页面时呼出暂停框，可**退回到主菜单**或**退出游戏**，再按 Esc 继续游戏。
- 开发验收统一走屏幕上的「调试台」，不再使用 F1 / F3 / I 快捷键。
- 当前回合技能不因中途调整理智重抽，下一角色回合开始才更新。

## 可编辑内容

数据在 `Assets/StageOne/Resources/StageOne`：

- `GameCatalog.asset`：队伍、敌人及全局概率强度、反馈系数和死亡概率。
- `Characters`：角色与敌人的生命、速度、战斗属性及**三份技能列表**（常态 / 低理智 / 高理智特殊技能）。
- `Skills`：伤害、作用范围、治疗、次数、流血与打断。

站位掩码采用位置1至4对应1、2、4、8，例如3表示位置1和2，15表示全部位置。完整的字段说明、敌人编队编辑方式和 Battle Lab 调参固化流程见 [数据修改指南](Docs/数据修改指南.md)。

## 结构与验证

`Core`是无Unity依赖的规则层；`Runtime`是数据适配和uGUI表现；`Editor`负责生成入口与构建；`Tests`包含规则与场景测试。

通过Unity Test Runner运行EditMode及PlayMode测试。菜单 **GameMake → Build Stage One Windows** 生成开发试玩版至工作区 `交付/阶段一/Windows试玩版`。

开发试玩中的验收工具是屏幕上的「调试台」，只存在于编辑器与 Development Build；正式发行构建不包含它，也不包含任何特殊功能键。

完成本阶段后暂停，等待用户验收通过，再进入第二阶段。
