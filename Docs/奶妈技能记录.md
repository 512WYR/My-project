# 奶妈技能记录

> 游戏内描述第一行只写位置符号：`●` 表示可选/可施放，`○` 表示不可选；斜杠前为己方站位，斜杠后为合法目标位置，均按 1→4 号位排列。目标阵营与「不能选自己」等限制写在第二行效果说明里。
>
> 游戏内描述中的「预计 X 点」按初始攻击力 10 计算，未计目标防御、暴击与肢体减益。

## 技能1：放血

| 项目 | 已确认设定 |
| --- | --- |
| 效果 | 对一名敌人造成伤害，并施加两次流血 |
| 施放站位 | 奶妈处于己方1号位或2号位 |
| 可选目标 | 敌方1号位或2号位中的一个敌人 |
| 目标数量 | 单体 |

直接伤害数值、每次流血的伤害及持续时间、流血结算与叠加规则、行动消耗及其他未指定参数待定。“两次流血”按用户原话保留，不自动改为“两回合流血”或“两层流血”。

## 技能2：流血奶

| 项目 | 已确认设定 |
| --- | --- |
| 效果 | 对一名己方角色进行治疗，恢复稍微大量的生命值 |
| 附带风险 | 有50%概率对被治疗角色施加3层流血 |
| 施放站位 | 奶妈处于己方2号位或3号位 |
| 可选目标 | 己方1、2、3、4号位中的一名角色，包含奶妈自己 |
| 目标数量 | 单体 |

治疗量按用户“稍微大量治疗”的描述记录，具体数值待定。流血伤害、持续时间、结算与叠加规则、行动消耗及其他未指定参数待定。50%概率对应施加3层流血的整体事件，不自动改为每层独立判定。

## 技能3：群体药雾

| 项目 | 已确认设定 |
| --- | --- |
| 效果 | 使用后为己方全体角色恢复少量生命值 |
| 施放站位 | 奶妈处于己方3号位或4号位 |
| 生效对象 | 己方1、2、3、4号位的全体角色，包含奶妈自己 |
| 目标数量 | 己方全体 |

具体治疗数值、行动消耗及其他未指定参数待定，不自动添加持续治疗或其他附加效果。

## 技能4：驱散疗法

| 项目 | 已确认设定 |
| --- | --- |
| 效果 | 为己方每名角色各随机移除一种减益效果（debuff） |
| 施放站位 | 奶妈处于己方4号位 |
| 生效对象 | 己方1、2、3、4号位的全体角色，包含奶妈自己 |
| 目标数量 | 己方全体 |

可驱散的减益范围、对多层减益的移除方式、与肢体损伤减益的交互、行动消耗及其他未指定参数待定。不自动添加生命恢复效果。

## 低理智状态：技能变化

| 项目 | 已确认设定 |
| --- | --- |
| 生效条件 | 奶妈处于低理智状态 |
| 失去的技能 | 低理智状态下无法使用技能1放血、技能3群体药雾、技能4驱散疗法 |
| 可用技能 | 仅可使用技能2流血奶，且仍须满足施放站位要求 |
| 技能2目标变化 | 改为随机一名角色受到治疗 |
| 技能2流血变化 | 施加的流血层数增加，相比常态3层更高，具体层数待定 |
| 施放站位 | 不变，沿用技能2：己方2号位或3号位 |
| 治疗量 | 比常态技能2提高，具体增幅待定 |
| 流血施加概率 | 沿用常态技能2的50%，未指定变化 |
| 目标数量 | 单体 |

低理智阈值、治疗量的具体增幅、增加后的具体流血层数、随机治疗的候选角色范围及其他未指定参数待定。不自动改为必定施加流血。处于己方1号位或4号位时，仍不满足技能2的施放站位要求。

## 高理智特殊技能：吸血扩散

| 项目 | 已确认设定 |
| --- | --- |
| 解锁条件 | 奶妈处于高理智状态 |
| 使用限制 | 解锁后，每场战斗累计最多使用3次 |
| 次数统计范围 | 单场战斗累计，进入下一场战斗时重置；同一场战斗内再次解锁不刷新次数 |
| 施放站位 | 奶妈处于己方2、3、4号位 |
| 可攻击目标 | 敌方1、2、3号位中的一名敌人 |
| 攻击效果 | 对所选敌人造成伤害 |
| 治疗主目标 | 奶妈自身 |
| 治疗效果 | 以自身为主目标进行治疗，并向自身左右直接相邻的己方角色扩散治疗（存在时） |
| 扩散治疗量 | 每名相邻角色获得主目标治疗量50%的治疗 |
| 攻击目标数量 | 单体 |
| 治疗目标数量 | 最多3名：奶妈自身及左右各1名相邻队友 |

治疗范围示例（相应位置存在队友时）：奶妈位于2号位，治疗自身并扩散至1、3号位；位于3号位，治疗自身并扩散至2、4号位；位于4号位，治疗自身并扩散至3号位。扩散不会继续传递。

此技能独立于4个常规技能。高理智阈值、攻击伤害、自身治疗量、伤害与治疗量是否关联及其公式、扩散以主目标名义治疗量还是实际恢复量计算、攻击未命中时是否仍治疗、行动消耗及其他未指定参数待定。不自动添加每场战斗限用1次、清除流血或其他此前建议中的效果。

## 实现取值（暂定）

以下数值逐条对应上文「待定」，全部集中在 `Assets/StageOne/Editor/StageOneBuild.cs` 的 `Medic()` 一处。
通用口径与前几份文档相同：伤害与治疗量 = 奶妈攻击力 × 倍率向上取整（奶妈初始攻击 10）、治疗不会超过目标生命上限、
形态门控为理智 > 70 / < 30 且权重 0.2 / 0.6 / 0.2。

| 技能 | 待定项 | 暂定取值 |
| --- | --- | --- |
| 放血 | 直接伤害 | 攻击力 × 0.6（约 6 点） |
| 放血 | 「两次流血」的口径 | 按字面实现为**两段流血**：每段 2 点伤害、共 2 次行动（合计 4 点），不是「两回合」也不是「两层叠加」 |
| 放血 | 流血结算与叠加规则 | 同一个目标身上只有一份流血状态，再次施加会覆盖而不是叠层 |
| 流血奶 | 治疗量 | 攻击力 × 1.4（约 14 点），即全队最高的单体治疗 |
| 流血奶 | 流血伤害与持续时间 | 与放血同口径：3 点、2 次行动；50% 判定的是「是否施加」这一整件事，不逐层判定 |
| 流血奶 | 可治疗对象 | 己方 1–4 号位含奶妈自己；满血队友不算合法目标（避免空放） |
| 群体药雾 | 治疗数值 | 每人攻击力 × 0.5（约 5 点） |
| 驱散疗法 | 可驱散的减益范围 | 目前引擎建模的减益只有流血，所以实现为清除流血；后续加入新的减益类型时在这里扩展 |
| 驱散疗法 | 多层减益的移除方式 | 一次清空该角色身上的流血，不按层数逐条移除 |
| 驱散疗法 | 与肢体损伤的交互 | 不涉及：肢体损伤是独立系统，不属于可驱散的减益 |
| 流血奶·渴求 | 治疗量增幅 | 攻击力 × 1.6（约 16 点），比常态的 1.4 高约 14% |
| 流血奶·渴求 | 增加后的流血层数 | 4 点、2 次行动（常态为 3 点） |
| 流血奶·渴求 | 随机治疗的候选范围 | 己方 1–4 号位中生命未满的任意角色，包含奶妈自己；在候选里随机抽一名（消耗一次随机抽取） |
| 吸血扩散 | 攻击伤害 | 攻击力 × 1.0（约 10 点） |
| 吸血扩散 | 自身治疗量与公式 | 按**实际造成的伤害** 1:1 治疗自身，所以打在防御高的敌人身上治疗量会变低 |
| 吸血扩散 | 扩散治疗量 | 主目标治疗量的 50%，左右相邻各一名，不继续向外传递 |
| 吸血扩散 | 攻击未命中时是否仍治疗 | 不治疗：未命中即伤害为 0，治疗量随之为 0 |
| 吸血扩散 | 使用次数 | 每场 3 次（已按文档实现），跨战斗重置 |


## 义体替换技能（已实装）

奶妈的两件专属义体只替换当前形态实际拥有的技能；义体随头部或手臂断肢而销毁，技能随即恢复原版。数值与完整规则见 [义体体系实现说明.md](义体体系实现说明.md)。

| 义体 | 替换/修改 | 效果 |
| --- | --- | --- |
| 狂医手术镜（头部） | 流血奶、流血奶·渴求（低理智） | 治疗量 +80%；流血概率由 50% 提升到 100%，流血层数保持常态 3 / 低理智 4 |
| 高压灌药臂（手臂） | 群体药雾 → **沸血药雾** | 施放位己方 3/4；全队含自身各恢复攻击力 125% 的生命；治疗后每名接受者获得 2 点流血、持续 2 次行动，满血角色也会获得；无持续治疗；耗 1 矿石 |

沸血药雾的流血比奶妈常规流血弱，因此只会在目标没有更强流血时覆盖，避免把 3 点或 4 点流血削弱成 2 点。
