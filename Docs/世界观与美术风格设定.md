# 世界观与美术风格设定

更新日期：2026年10月25日

本文记录世界观与美术的统一方向。第一节为已经确认的要求；后续章节为据此提出的设计建议，供场景、角色、义体与叙事设计使用。

## 1. 已确认的风格方向

**整体以蒸汽朋克为基底，社会呈现原子朋克的光鲜亮丽与大企业管控，下矿角色呈现柴油朋克的粗糙感。**

| 层面 | 风格定位 | 需要传达的感受 |
| --- | --- | --- |
| 整个世界 | 蒸汽朋克 | 庞大的工业文明、沉重的机械结构，以及围绕生产与能源形成的社会秩序 |
| 企业与社会表象 | 原子朋克 | 明亮、整洁、繁荣、对未来充满承诺；生活与资源受到大企业掌控 |
| 下矿角色 | 柴油朋克 | 厚重、耐用、磨损、油污与修补痕迹；人依靠装备和经验在恶劣环境中生存 |

三种风格分别服务于世界结构、企业形象和劳动者处境，在同一个世界中相互联系。

## 2. 世界结构建议

蒸汽朋克贯穿城市、工业区与矿井：高耸厂房、砖石拱廊、铆接钢梁、巨型升降机、压力管道与成组阀门共同构成环境。机器需要空间、维护和人力，玩家能看见生产如何运行。

企业的明亮门厅可以建在旧工业建筑中；抛光外壳后方仍能接入粗大的压力管道；整洁的矿井服务站可以与满是煤灰的作业区只隔一道门。通过这些连接，让三个层面的风格保持连续。

具体能源体系、原子能是否真实存在、矿石的性质以及技术发展史，留待剧情设定确定。“原子朋克”在当前约定中首先规定视觉气质与未来想象。

## 3. 企业的光鲜与管控建议

企业面向公众的空间采用圆润外壳、搪瓷、镀铬、磨砂玻璃与整齐的灯箱。建议以奶油白、薄荷绿、浅蓝和明快的暖色点缀，呈现值得向往的生活。

光鲜生活应当具有实际吸引力：照明充足、设备好用、公共服务井然有序，宣传中的舒适确实有人享有。压迫感从使用这些服务所需的资格、费用与服从中逐渐显现。

| 可选的管控表现 | 可以放进画面的细节 |
| --- | --- |
| 工作与通行 | 企业工牌、矿区闸门、电梯权限、班次广播 |
| 资源与维修 | 印有企业标识的补给、配给凭证、指定维修窗口 |
| 信息与宣传 | 笑脸广告、产量荣誉榜、事故后的统一广播口径 |
| 人身与医疗 | 工伤登记、义体保修条款、服务资格审核 |

这些属于叙事与美术建议；债务、收费、通行限制等是否成为玩法，需要另行设计。

企业形象也可以进入矿井：一块干净明亮的广告牌、一台仍在播放快乐广播的终端，都能把企业权力带到劳动现场。

## 4. 下矿角色的粗粝感建议

角色首先应让人看出其作业能力：厚帆布、旧皮革、粗钢板、工装绑带、护目镜、防尘面罩、沉重工靴，以及便于戴手套操作的大把手。

装备的磨损要有使用逻辑：手掌和把手处磨亮，关节积油，靴底与衣摆沾泥，受力处有焊补，面罩上留有擦拭过的清晰区域。角色会维护赖以生存的工具，也会保留各自的习惯与个人物件。

建议配色为煤黑、铁灰、油褐与褪色军绿，局部使用警示黄、氧化红或旧工牌颜色，保持战斗中的轮廓辨识。

现有四名角色可沿各自功能形成区别，以下仅为外观方向：

| 角色 | 可采用的外观重点 |
| --- | --- |
| 战士 | 重型作业工具、加固护臂、便于发力的工装与磨损护具 |
| 盾卫 | 厚重防护板、承重支架、稳定支撑结构与撞击痕迹 |
| 枪手 | 机械瞄具、弹药携行具、擦拭维护过的枪械与油污手套 |
| 奶妈 | 野战医疗包、药瓶、压力喷雾装置与反复消毒的金属器具 |

## 5. 统一装备与义体的设计建议

企业设备与矿工装备可以使用相同的生产编号、接头规格、仪表刻度和厂商标识。企业展示品拥有完整外壳与整齐布线；矿井中的同系列产品已经掉漆、拆修、替换零件，暴露出内部结构。

现有义体可继续保留蒸汽、压力、活塞与机械传动的视觉语言，再通过粗钢护壳、油管、维修焊缝和绑带体现下矿者的使用状态。企业高级型号则可采用封闭外壳、搪瓷与镀铬表面。

齿轮、铜管与铆钉优先出现在具有传动、输送或固定功能的位置。不同角色通过装备结构、维修方式与个人物件体现性格。

## 6. 与当前游戏的结合建议

- 矿井、电梯井与作业机械承担蒸汽朋克的环境基底；补给站、企业标识与广播把光鲜的企业形象带入地下。
- 肢体损伤与义体表现劳动者身体所承受的代价。磨损、替换零件与维修记录可以加强这种感受。
- 现有理智系统可通过事件逐步揭示宣传与现场记录之间的矛盾；企业管控也应通过闸门、工牌、价目和广播等可观察细节呈现。
- 现有暗色工业界面可延续压力表、机械计数器与金属框架；明快配色用于企业宣传与服务设施。哥特式拱形可作为工业建筑细节，整体仍以本文件的三层关系为准。

可用这一幕检验风格是否统一：**明亮的企业广告悬在巨型蒸汽升降机上方，承诺人人都能享有美好的明天；广告下面，满身油污与矿尘的人正在检查修补过的义肢，等待下一班下井。**

本文件确立美术与叙事方向。企业名称、具体历史、能源原理、角色背景及企业管控的玩法效果均待后续设计确定。
