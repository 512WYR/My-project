## 1. 一页速览

「持续」一栏里的「本回合」指到下一次回合开始为止，不按角色自己的行动次数计算。

| 名称 | 类型 | 数值 / 效果 | 持续 | 主要来源 |
|---|---|---|---|---|
| 格挡 | 正面 | 每层完全免除一次攻击的伤害与附带效果（流血、理智、失衡、部位磨损） | 消耗 1 层；回合开始清空剩余层数 | 盾卫「格挡」「全队格挡反击」 |
| 反击 | 正面 | 格挡成功、受到攻击或替队友承伤后，以自身攻击力 100% 反击一次 | 触发一次后消失；回合开始清空 | 盾卫「守护·血怒」「全队格挡反击」 |
| 追击 | 正面 | 被增益英雄对敌人造成伤害后，追加攻击力 50%（当前全队攻击力 10，即 5 点） | 本回合；不消耗，可多次触发 | 战士「追击」 |
| 防御力+ | 正面 | 防御值 +20 个百分点，等效减少 20% 受到的伤害 | 本回合；同类取最高 | 盾卫「壁垒」 |
| 命中+ | 正面 | 命中率 +20 个百分点 | 本回合；同类取最高 | 枪手「军备补充」 |
| 守护 | 正面（转移） | 针对被守护者的攻击由守护者承受 | 到守护者自己的下一次行动开始 | 盾卫「守护」「守护·血怒」；肉盾怪「守护」 |
| 攻击力+ | 正面（饰品） | 成瘾物 +30%；跃动心脏 +50%（失败后降至 30%） | 见第 3.7 节 | 成瘾物、跃动心脏 |
| 流血 | 负面 | 每次自身回合开始时受到 N 点伤害，共 T 次 | 见第 4.1 节 | 奶妈「放血」「流血奶」、流血怪、穿肠弹 |
| 失衡 | 负面 | 跳过下一次行动；位移必中 | 跳过 1 次行动；位移窗口 2 回合 | 战士「猛击」 |
| 打断 | 负面（控制） | 跳过下一次行动 | 1 次 | 枪手「阻断射击」「贯穿弹」 |
| 易伤 | 负面 | 受到的伤害 +N% | 本回合 / 按饰品层数 | 战士「带伤强攻」自身 +25%（当前未生效，见 9.4）；成瘾物每层 +15%；锈血勋章 +5% |
| 受伤 | 部位损伤 | 部位生命 ≤50%，对应属性下降 | 修复部位前 | 受击磨损 |
| 断肢 | 部位损伤 | 部位生命 =0，对应属性大幅下降 | 安装义肢前 | 受击磨损 |
| 假寐 | 负面（饰品） | 每回合理智 -10；致命伤吞掉一次 | 触发后 2 回合 | 假寐的药剂 |
| 理智锁定 | 中性（道具） | 本场战斗理智不增不减 | 整场战斗 | 理智锁定药剂 |
| 锁血 / 锁肢 | 特殊（饰品） | 生命不低于 1，部位不受伤害 | 装备期间 | 金丝苹果 |
| 跃动心脏 | 特殊（饰品） | 标记敌人；攻击 +50% 且每回合追加一次行动 | 整场或第 3 回合失败 | 跃动心脏 |
| 殉道锁链 | 特殊（饰品） | 生命归零时消耗 1 个未断部位，把生命恢复到最大生命的 20% | 装备期间 | 殉道锁链 |
| 献血针筒 | 特殊（饰品） | 治疗量 +100%；每次治疗技能令随机一名存活队员损失 20% 最大生命 | 装备期间 | 献血针筒 |
| 濒死 | 特殊 | 生命为 0 仍存活；再次受伤进行死亡检定 | 直到被治疗或死亡 | 任意致命伤 |

## 2. 通用规则

1. **状态只有一个来源**：所有临时状态都写在 `ActorState` 上，战斗界面的状态条直接读取引擎字段，没有另一套计时器，因此不会出现「显示还在、实际已失效」的偏差。
2. **回合开始统一清理**：新回合开始时清空防御力、命中、易伤（`SelfVulnerable`）、格挡层数、反击、追击与追击攻击力。见 `BattleEngine.Advance`。
3. **守护单独计时**：守护不随回合清理，而是持续到守护者自己的下一次行动开始；被守护者的 `ProtectorId` 会在守护者回合开始时清掉。守护者死亡时重定向立即失效。
4. **一次性效果**：格挡按层消耗；反击触发一次后立即置否；追击持续整回合、可触发多次，但追击本身不会再次引发追击。
5. **叠加方式不统一**：格挡层数累加；防御力、命中、易伤（本回合）取最高值；成瘾物易伤按层线性叠加；流血按来源决定覆盖还是累加（见 4.1）。
6. **每回合检查顺序**：角色回合开始时依次结算「流血 → 打断 → 失衡」，然后才进入正常行动。流血可以致死，死亡后不再检查打断/失衡。
7. **部位只属于英雄**：`LimbSystem.Damage` 对敌人直接返回，怪物不会断肢；义肢让该部位的属性因子回到 1，但已断的部位仍会在状态条显示为「义肢·部位」。
8. **格挡优先于一切受击效果**：命中、闪避判定之后立刻检查格挡；触发格挡时该次攻击的伤害、流血、理智、失衡与部位磨损全部不发生，只结算反击。

## 3. 正面增益

### 3.1 格挡（Block）

| 项目 | 内容 |
|---|---|
| 字段 | `ActorState.BlockCharges`（整数层数） |
| 效果 | 每次攻击进入受击结算时消耗 1 层，完全免除该次伤害与所有附带效果 |
| 获得 | 盾卫「格挡」给 1 名队友 1 层；「全队格挡反击」给全队各 1 层 |
| 持续 | 未消耗的层数在下一次回合开始时清空 |
| 叠加 | 层数直接相加（`BlockCharges++`），同一角色可以有多层 |
| 例外 | 未命中或闪避不消耗格挡；流血结算不是攻击，不会被格挡；直接伤害（如献血针筒的代价）同样绕过格挡 |

实现位置：`BattleEngine.ConsumeBlock`；敌人攻击路径在命中/闪避判定后、伤害计算前调用。

### 3.2 反击（Counter）

| 项目 | 内容 |
|---|---|
| 字段 | `ActorState.Counter`（布尔） |
| 触发 | ① 格挡成功免除敌人攻击后；② 受到敌人攻击并实际承伤后（包括替队友承伤） |
| 效果 | 以自身攻击力 × `Rules.CounterRatio`（100%）反击攻击者，当前为 10 点 |
| 持续 | 触发一次即消耗；未触发则在本回合结束时清空 |
| 触发限制 | 未命中、闪避不触发；格挡成功虽然免除伤害，仍会触发反击；反击造成的伤害可以引发其他队友的追击 |
| 加成 | 复仇飞轮臂让反击伤害 +100%，但不增加反击次数 |

实现位置：`BattleEngine.TryCounter`。

### 3.3 追击（Followup）

| 项目 | 内容 |
|---|---|
| 字段 | `ActorState.Followup`、`FollowupAttack` |
| 触发 | 任意被增益英雄对敌人造成伤害后（普通攻击、技能、反击均可） |
| 效果 | 每名持有追击的英雄各追加一次 `FollowupAttack × Rules.FollowupRatio`（50%）的伤害 |
| 持续 | 本回合；不消耗，每次伤害都可触发 |
| 不连锁 | 追击伤害本身不会再触发追击 |
| 来源 | 战士「追击」给全队；`FollowupAttack` 记录施放者当时的攻击力（当前全队均为 10，追击 5 点） |

实现位置：`BattleEngine.TryFollowups`。

### 3.4 防御力+（DefenseUp）

| 项目 | 内容 |
|---|---|
| 字段 | `ActorState.DefenseBuff`（小数，0.2 = 20 个百分点） |
| 效果 | `EffectiveDefense = (基础防御 + DefenseBuff) × 部位因子`；当前英雄基础防御为 0，因此等效减伤 20% |
| 获得 | 盾卫「壁垒」给全队 +20% |
| 持续 | 本回合 |
| 叠加 | 同类取最高（`Math.Max`），不会叠加到 40% |
| 边界 | 与躯干受伤/断肢的防御因子相乘；与易伤、饰品减伤分别独立结算 |

实现位置：`BattleEngine.ApplyBuffs`、`EffectiveDefense`。

### 3.5 命中+（AccuracyUp）

| 项目 | 内容 |
|---|---|
| 字段 | `ActorState.AccuracyBuff`（小数，0.2 = 20 个百分点） |
| 效果 | 基础命中率先乘头部部位因子，再加 20 个百分点、技能命中修正与义肢命中偏移，最后夹在 0～1 |
| 获得 | 枪手「军备补充」给全队 +20%；被选中的队友同时恢复 10 点理智（属于即时治疗，不是 Buff） |
| 持续 | 本回合 |
| 叠加 | 同类取最高 |
| 上限 | 满状态英雄基础命中 90%，+20 个百分点后触顶 100%，实际只提升 10 个百分点；头部受伤时会先被部位因子压低，再加这 20 点 |
| 特殊 | 穿肠弹的「命中率不低于 90%」是下限，不叫命中 Buff，但会参与最终命中率计算 |

实现位置：`BattleEngine.EffectiveAccuracy`、`ApplyBuffs`。

### 3.6 守护（Protect）

| 项目 | 内容 |
|---|---|
| 字段 | 被守护者的 `ActorState.ProtectorId`；守护者的 `GuardReduction` |
| 效果 | 针对被守护者的攻击改由守护者承受；命中、闪避、格挡、部位磨损全部按守护者结算 |
| 持续 | 到守护者自己的下一次行动开始（可跨回合） |
| 获得 | 盾卫「守护」「守护·血怒」（给队友）；肉盾怪「守护」（给敌人） |
| 减伤 | 肉盾怪的白板守护没有减伤；精英肉盾怪拦截伤害 -25%；殉道锁链让盾卫的拦截伤害再 -50%（乘算） |
| 边界 | 只重定向一层，守护者不能再把伤害转给第三个人；守护者死亡时攻击回到原目标；「守护·血怒」同时给守护者自身反击 |

实现位置：`BattleEngine.ApplySupport`、`HeroGuardTarget`、`GuardedTarget`、`ReduceForGuard`。

### 3.7 攻击力加成（饰品常驻）

| 来源 | 数值 | 期间 | 备注 |
|---|---|---|---|
| 成瘾物 | 攻击力 +30% | 入场后到持有者击杀任意敌人为止 | 击杀后 `AddictionActive=false`，加成与理智回复、易伤一并失效；队友击杀不会解除 |
| 跃动心脏（成功） | 攻击力 +50% | 整场 | 标记目标在第 2 回合结束前死亡即锁定成功 |
| 跃动心脏（失败） | 攻击力 ×30% | 从第 3 回合起整场 | 失去每回合的追加行动 |

这两种加成通过 `AccessorySystem.AttackMultiplier` 直接乘在攻击力上，不经过 `AllyBuff`，因此不会显示成「攻击力+」的临时 Buff；状态条仍会以「攻击力 +30% / +50%」条目显示。

## 4. 负面减益与部位损伤

### 4.1 流血（Bleed）

| 项目 | 内容 |
|---|---|
| 字段 | `ActorState.BleedDamage`（每次伤害）、`BleedTurns`（剩余次数） |
| 结算时机 | 角色自己的回合开始时，行动之前；`BleedTurns--` 后立刻造成 `BleedDamage` 点伤害 |
| 伤害性质 | 无视防御、格挡、易伤与绝大多数饰品减伤；双泵再生胸腔会让流血伤害 ×2 |
| 致死 | 可以致死；死亡后跳过该角色本回合行动，并先处理敌方站位空缺 |
| 施加 | 奶妈「放血」2×2；「流血奶」3×2（50%）；「流血奶·渴求」4×2（50%）；流血怪 2×2、精英 3×2；旧版猎人行为 2×2 |
| 覆盖规则 | 技能/敌人施加时**覆盖**：`BleedDamage = 新值`，`BleedTurns = 新次数`（至少 1），不会把旧次数加进去 |
| 累加规则 | 穿肠弹每次命中给自身 `BleedDamage += 2`，`BleedTurns = max(当前, 2)`，这是唯一会累加伤害的来源 |
| 清除 | 奶妈「驱散疗法」清全队流血；带 `Cleanse` 的治疗也会清目标流血；战斗结束/新战斗重置 |

实现位置：`BattleEngine.Advance`（结算）、`ApplySupport`（施加与清除）、`ApplyAttackAccessories`（穿肠弹）。

### 4.2 失衡（Imbalance）

| 项目 | 内容 |
|---|---|
| 字段 | `ActorState.Imbalance`、`ImbalanceImmuneRound`、`ImbalanceAutoHitUntilRound` |
| 效果 | 下一次行动被跳过；位移技能在窗口内对目标必定命中 |
| 持续 | 跳过行动只消耗 1 次；位移必中从施加回合起共 2 回合（`Rules.ImbalanceAutoHitRounds`） |
| 免疫 | 施加后的下一回合（`Rules.ImbalanceImmuneRounds = 1`）内再次失衡无效，防止连续控制 |
| 来源 | 战士「猛击」（0.7 倍伤害并施加失衡） |
| 预告 | 敌方卡片显示「失衡：下次行动跳过 · 位移必中」或「失衡余波：位移必中」 |

实现位置：`BattleEngine.ApplyOnHit`、`Advance`、`Intent`。

### 4.3 易伤（Vulnerable）

易伤在本作里有三个独立来源，界面都会显示为「易伤 +N%」，但计算方式不同：

| 来源 | 数值 | 持续 | 叠加 |
|---|---|---|---|
| 战士「带伤强攻」自身代价 | 设计值 +25% | 本回合 | 每回合重置；**当前引擎没有把技能数据写入角色状态，暂不生效**（见 9.4） |
| 成瘾物 | 每层 +15%，最多 10 层（最高 +150%） | 直到击杀敌人或战斗结束 | 每次攻击 +1 层，线性叠加 |
| 锈血勋章 | 受到伤害 +5% | 整场 | 不叠加，与成瘾物乘算 |

结算顺序：防御减伤 → 易伤放大 → 饰品受伤系数 → 义肢受伤系数，最后向上取整、至少 1 点。

### 4.4 受伤与断肢（Limb）

部位生命是一条只降不升的独立轨道，只对英雄生效。每次实际命中并造成伤害的敌人攻击会磨损一个随机未断部位；磨损量按实际承伤 ×`Rules.Limbs.DamageRatio`（50%）计算。

**阈值**

- `Intact`：部位生命 > 50% 最大生命。
- `Injured`（界面写作「受伤」）：部位生命 ≤ 50%，对应属性下降。
- `Severed`（界面写作「断肢」）：部位生命 = 0，对应属性大幅下降。

**默认部位表**（`LimbSystem.DefaultParts`）

| 部位 | 部位生命 | 受伤减益（≤50%） | 断肢减益（=0） | 影响 |
|---|---|---|---|---|
| 头部 | 最大生命 30% | 命中 ×0.90 | 命中 ×0.75 | 命中率 |
| 躯干 | 最大生命 45% | 防御 ×0.80 | 防御 ×0.60 | 减伤 |
| 手臂 | 最大生命 35% | 攻击 ×0.80 | 攻击 ×0.55 | 攻击力 |
| 腿部 | 最大生命 35% | 速度 ×0.80 | 速度 ×0.55 | 行动顺序 |

**规则**

1. 断肢优先于受伤，两者不叠加；每个部位只按最差状态计算一次。
2. 部位生命不会自然恢复；受伤可以在补给站修复，断肢只能安装义肢。
3. 安装义肢后该部位属性因子回到 1，并可附带义肢本身的效果；义肢会随部位再次断裂而损毁。
4. 金丝苹果的「部位不受伤害」会让 `WearLimb` 直接返回，不消耗随机数。
5. 穿肠弹每次命中让自身随机部位 -1；假寐药剂触发时按部位最大生命的 50% 重创一个随机部位。
6. 演出只在跨越阈值时提示：普通磨损只进战斗日志，部位降到一半显示「受伤 -N」，归零显示「断肢！」。

实现位置：`LimbSystem.ConditionOf`、`Damage`、`BattleEngine.WearLimb`、`BattleStatus.AddLimbs`。

### 4.5 假寐（SleepPotion）

| 项目 | 内容 |
|---|---|
| 来源 | 饰品「假寐的药剂」，每场战斗一次 |
| 触发 | 一次会致死的攻击到来时，伤害归零，`SleepTurns = 2` |
| 代价 | 随机部位受到该部位最大生命 50% 的伤害；理智 -10 |
| 持续 | 之后每个回合开始时理智 -10，共 2 次 |
| 限制 | 触发后不再吞第二次致命伤；部位被金丝苹果锁定时不掉部位 |

## 5. 控制与特殊状态

### 5.1 打断（Interrupt）

| 项目 | 内容 |
|---|---|
| 字段 | `ActorState.Interrupted`（整数，表示待打断的行动次数） |
| 效果 | 下一次行动直接跳过，消耗 1 层 |
| 来源 | 枪手「阻断射击」（单体，每场 2 次）；「贯穿弹」（只打断主目标，每场 3 次） |
| 限制 | 只对敌人生效（`!target.Player`），只对技能主目标生效，溅射目标只受伤不打断 |
| 叠加与免疫 | 没有免疫；重复施加取 `max`，不会叠加成两次跳过 |

### 5.2 理智锁定（SanityLock）

| 项目 | 内容 |
|---|---|
| 字段 | `ActorState.SanityLocked`（战斗内）、`SanityLockPending`（战斗外预置） |
| 效果 | 本场战斗内理智增减全部被拒绝，只写一条日志；同时跳过金丝苹果的理智归零死亡判定 |
| 来源 | 一次性道具「理智锁定药剂」 |
| 持续 | 整场战斗；战斗结束（胜/败/撤退）统一清空 |
| 边界 | 不能重复叠加；对已锁定目标再次使用会被拒绝且不扣库存 |

### 5.3 金丝苹果

| 项目 | 内容 |
|---|---|
| 类型 | 饰品常驻，不进入 `AllyBuff`，但会在状态条显示相关条目 |
| 锁血 | 受到伤害后生命最低保留 1 点 |
| 锁肢 | 部位不受任何伤害，包括穿肠弹与假寐药剂 |
| 理智代价 | 每次被攻击理智 -5；理智归零时按 `Rules.DeathChance` 做一次直接死亡判定 |
| 基础加成 | 装备时最大生命 +10 |
| 边界 | 流血不会触发理智扣除（`bleeding` 分支跳过）；理智锁定时不会触发归零死亡 |

### 5.4 跃动心脏

| 项目 | 内容 |
|---|---|
| 标记 | 入场随机标记一名存活敌人，名字后显示 ⊕ |
| 成功条件 | 标记目标在第 2 回合结束前死亡（任何来源均可） |
| 成功效果 | 攻击 +50% 持续整场；每回合在持有者行动后立即追加 1 次行动 |
| 失败 | 第 3 回合起攻击降为 30%，失去追加行动 |
| 边界 | 追加行动通过回合队列插入，不额外增加速度判定；失败状态在状态条显示为「攻击力 -70%」 |

### 5.5 殉道锁链

| 项目 | 内容 |
|---|---|
| 类型 | 盾卫专属饰品 |
| 防护 | 代守时拦截的伤害 -50%（与精英肉盾的 25% 乘算） |
| 触发 | 生命将归零时，消耗 1 个未断部位，把生命恢复到最大生命的 20%（至少 1 点），理智 -10 |

| 边界 | 直接伤害（`direct`）不触发，流血可以触发；触发后本次伤害不再扣血 |

### 5.6 献血针筒

| 项目 | 内容 |
|---|---|
| 类型 | 奶妈专属饰品 |
| 增益 | 所有治疗量 ×2 |
| 代价 | 每次施放治疗技能后，随机一名存活队员损失 20% 最大生命（至少 1 点，可能选中自己） |
| 边界 | 群体治疗只扣一次；扣血不触发受击类效果（按直接伤害处理） |

### 5.7 濒死（DeathDoor）

| 项目 | 内容 |

| 字段 | 派生属性 `ActorState.DeathDoor = Player && !Dead && Hp <= 0` |

| 结束 | 检定失败死亡；被治疗恢复生命后脱离濒死 |

## 7. 叠加、清除与免疫

| 状态 | 叠加 | 清除 / 结束 | 免疫或例外 |
|---|---|---|---|
| 格挡 | 层数相加 | 消耗；回合开始清空 | 流血等非攻击伤害不消耗格挡 |
| 反击 | 不叠加（布尔） | 触发一次；回合开始清空 | 未命中/闪避不触发 |
| 追击 | 不叠加；可多次触发 | 回合开始清空 | 追击不连锁 |
| 防御力+ | 取最高 | 回合开始清空 | — |
| 命中+ | 取最高 | 回合开始清空 | — |
| 守护 | 一个被守护者只能有一个守护者 | 守护者下次行动开始；守护者死亡 | 只重定向一层 |
| 流血 | 技能覆盖，穿肠弹累加 | 按次数耗尽；驱散疗法；战斗结束 | 无视防御/格挡 |
| 失衡 | 不叠加；重复施加受免疫限制 | 跳过 1 次行动 | 施加后下一回合免疫 |
| 打断 | 取 max | 跳过 1 次行动 | 只对敌人主目标 |
| 易伤（本回合） | 取最高 | 回合开始清空 | — |
| 成瘾易伤 | 每层 +15%，最多 10 层 | 持有者击杀敌人；战斗结束 | 与锈血勋章乘算 |
| 受伤 / 断肢 | 每个部位独立，按最差状态 | 修复或安装义肢 | 义肢使属性因子回到 1；金丝苹果锁肢 |
| 假寐 | 每场只触发一次 | 2 次回合结算后结束 | 金丝苹果锁肢时不掉部位 |
| 理智锁定 | 不可叠加 | 战斗结束 | 阻止一切理智变化 |
| 跃动心脏 | 每个持有者独立 | 整场；失败从第 3 回合生效 | 标记目标死亡即锁定成功 |

**清空时机一览**

- 新回合开始：防御力、命中、自身易伤、格挡层数、反击、追击、追击攻击力。
- 守护者回合开始：被其守护的所有 `ProtectorId`。
- 角色回合开始：先扣流血次数并结算，再消耗打断，再消耗失衡。
- 战斗结束：所有角色的临时状态与理智锁定一起清空；跨战斗只保留生命、理智、部位和饰品。

## 8. 界面显示

### 8.1 状态条

状态条由 `Ruin.Core.BattleStatus` 汇总，战斗页卡片与全屏演出共用同一份数据。

显示顺序固定为：

`格挡 → 反击 → 追击 → 防御力 → 命中 → 守护 → 饰品（成瘾物攻击/易伤、跃动心脏、假寐、锈血勋章） → 流血 → 失衡 → 易伤 → 理智锁定 → 肢体（头 → 躯干 → 手臂 → 腿部）`

- 卡片立绘底部常驻摘要，最多 4 条，超出显示 `+N`；悬停显示完整条目与说明。
- 演出层在本次结果出现以下情况时，于受影响角色脚下显示当前全部状态：获得 Buff、部位跨阈值、理智被锁定。
- 状态条文本使用 ` · ` 连接；百分比统一保留 1 位小数。
- 已装义肢的部位显示为「义肢·部位」，不再标红；已断部位显示为「断肢·部位」。
- 悬停详情 Canvas 排序为 70，高于演出层（60）；所有 Tooltip 图形不接收射线，不挡点击。

### 8.2 战斗演出提示

| 事件 | 头顶显示 | 说明 |
|---|---|---|
| 施加流血 | 金色「流血 N×T」 | 与造成伤害的行动同属一段演出 |
| 流血结算 | 红色当次伤害 + 「流血」 | 单独成为一段演出，站在流血者自己的立绘上 |
| 部位受伤 | 琥珀「部位 受伤 -N」 | 只在部位首次降到一半时出现 |
| 部位断肢 | 橙红「部位 断肢！」 | 只在部位归零时出现 |
| 普通部位磨损 | 不显示 | 只写入战斗日志 |
| 获得 Buff | 金色具体名称，如「格挡×1、防御力+20%」 | 多个效果用「、」连接并去重 |
| 理智变化 | 紫色「理智 -N」/ 青色「理智 +N」 | 与伤害可同屏显示 |
| 理智锁定 | 蓝灰「理智锁定」 | 不显示数值 |
| 失衡 | 脚下状态条 + 敌方行动预告 | 演出阶段本身不单独占一段 |
| 打断 | 仅敌方行动预告与战斗日志 | 不进入状态条；敌人行动时显示「下一次行动被打断」 |

演出最多同时归组 4 段行动、每段 4 个目标；超出部分只保留战斗日志。

### 9.3 新增一种 Buff 的检查清单

1. 在 `AllyBuff` 增加标志（如果是技能授予的团队增益），或在 `ActorState` 增加字段（如果是持续状态）。
2. 在 `ApplyBuffs` 中处理授予，写入具体的 `labels` 文本，保证演出能显示中文名。
3. 如果是临时状态，在 `BattleEngine.Advance` 的回合开始清理块中重置；如果是按次消耗，在触发点自行递减。
4. 在 `BattleStatus.Build` 增加条目（名称、数值、说明、语气），确认显示顺序。
5. 如果会影响伤害/命中/速度，接到对应的 `Effective*` 或 `Damage` 计算里，避免在多个调用点重复判断。
6. 补 `BattleStatusTests` / `BattleShowPlanTests`，并更新本文与相关技能记录。

### 9.4 已知边界

- **带伤强攻的自身易伤尚未接线**：`SkillSpec.SelfVulnerable = 0.25` 已写在技能数据与描述里，但 `BattleEngine.ResolveSkill` 没有把它写到 `actor.SelfVulnerable`，所以当前用后不会真的增加受伤，状态条也不会出现该条易伤。修复方式是在施放时按 `Math.Max` 写入；在修复前，本文与状态条都按「未生效」记录。
- 「本回合」类增益以回合为界，不按施放者的行动次数计算；回合末施放可能只覆盖敌方行动，收益偏低。
- 驱散疗法目前只能清除流血，因为流血是唯一实现了「可清除减益」的状态；新增减益时需要扩展 `Cleanse` 分支。
- 流血伤害日志与死亡事件都先于流血事件写入，演出分组靠目标最终状态判断死亡，避免把死亡归到上一段行动。
- 状态条只显示当前引擎状态，不记录历史；Buff 被消耗后下一次刷新立即消失。
