# 战士技能记录

> 游戏内描述第一行只写位置符号：`●` 表示可选/可施放，`○` 表示不可选；斜杠前为己方站位，斜杠后为合法目标位置，均按 1→4 号位排列。目标阵营与「不能选自己」等限制写在第二行效果说明里。
>
> 游戏内描述中的「预计 X 点」按初始攻击力 10 计算，未计目标防御、暴击与肢体减益。

## 技能1：斩劈

| 项目 | 已确认设定 |
| --- | --- |
| 效果 | 自身向前移动一位，并对一名敌人造成伤害 |
| 施放站位 | 战士处于己方1、2、3号位 |
| 可选目标 | 敌方1号位或2号位中的一个敌人 |
| 目标数量 | 单体 |
| 位于1号位时 | 原地攻击，不会因为无法前进而禁用技能 |

伤害数值、行动消耗及其他未指定参数待定。以本条用户确认设定为准，不沿用此前建议中的数值或附加机制。

## 技能2：猛击

| 项目 | 已确认设定 |
| --- | --- |
| 效果 | 对一名敌人造成较低伤害，技能命中后为其施加失衡效果 |
| 施放站位 | 战士处于己方1号位或2号位 |
| 可选目标 | 敌方1、2、3号位中的一个敌人 |
| 目标数量 | 单体 |
| 失衡：行动限制 | 目标跳过下一次行动 |
| 失衡：位移命中 | 猛击命中后，目标在2个回合内被位移技能命中的概率为100% |
| 失衡持续时间 | 位移必中持续施加回合与下一回合（共2回合）；行动限制仍只跳过下一次行动 |
| 后续免疫 | 进入失衡的敌人在下回合直接免疫失衡效果 |

失衡同时具有上述行动限制和位移技能必定命中的效果，两者持续时间独立：位移必中在施加回合与下一回合都有效，即使目标已经消耗掉被跳过的那次行动。伤害数值、猛击自身命中率、位移技能命中后与位移免疫或其他限制的交互、行动消耗及其他未指定参数待定。若目标在失衡施加前已经行动，其处理方式尚未确定。

## 技能3：扩散斩击

| 项目 | 已确认设定 |
| --- | --- |
| 效果 | 选择一名敌人作为主目标并造成伤害；主目标左右相邻存在其他敌人时，对这些相邻敌人造成扩散伤害 |
| 施放站位 | 战士处于己方2号位或3号位 |
| 可选主目标 | 敌方1、2、3号位中的一个敌人 |
| 扩散目标 | 主目标左侧与右侧直接相邻的敌人（存在时） |
| 扩散伤害 | 每名相邻敌人受到主目标所受伤害一半的伤害 |
| 目标数量 | 最多3名敌人：1名主目标及其左右各1名相邻敌人 |

范围示例（相应位置存在敌人时）：主目标为1号位，扩散至2号位；主目标为2号位，扩散至1、3号位；主目标为3号位，扩散至2、4号位。4号位不能被直接选为主目标，但可被扩散伤害波及。

主目标伤害数值、扩散伤害与各目标防御或格挡等效果的结算交互、取整方式、行动消耗及其他未指定参数待定。

## 技能4：带伤强攻

| 项目 | 已确认设定 |
| --- | --- |
| 效果 | 单次忽略肢体损伤造成的减益效果（debuff），攻击一名敌人 |
| 施放站位 | 战士处于己方1、2、3号位 |
| 可选目标 | 敌方1、2、3号位中的一个敌人 |
| 目标数量 | 单体 |
| 忽略减益的范围 | 仅本次攻击忽略肢体损伤造成的debuff，不代表移除这些减益 |
| 血量增伤 | 根据自身扣除的血量提高伤害 |
| 肢体损伤增伤 | 自身肢体有损伤时提供额外加伤，最多提供2层额外加伤 |
| 使用代价 | 使用后，提升自身该回合受到的伤害 |
| 使用限制 | 每场战斗仅可使用1次 |

基础伤害、扣除血量的计算口径与增伤公式、肢体损伤增伤层数的判定方式、每层额外加伤数值、使用后受到伤害的提升幅度、断肢导致技能禁用时与本技能的交互、行动消耗及其他未指定参数待定。不沿用此前建议中的具体数值或其他附加机制。

## 低理智状态：技能变化

| 项目 | 已确认设定 |
| --- | --- |
| 生效条件 | 战士处于低理智状态 |
| 失去的技能 | 低理智状态下无法使用技能1斩劈、技能2猛击、技能4带伤强攻 |
| 技能3变化 | 扩散斩击伤害提高，改为攻击1名主目标及其周边的1名敌人 |
| 主目标伤害 | 为常态扩散斩击主目标伤害的125% |
| 施放站位 | 沿用技能3：己方2号位或3号位 |
| 可选主目标 | 沿用技能3：敌方1、2、3号位中的一个敌人 |
| 敌方副目标范围 | 主目标左右相邻的敌人，最多选取其中1名 |
| 副目标伤害 | 副目标受到主目标所受伤害的75% |
| 误伤触发条件 | 主目标周边不存在可作为副目标的敌人时 |
| 误伤概率与对象 | 有30%概率将战士自身周边的1名队友作为副目标 |
| 误伤伤害 | 被作为副目标的队友同样受到主目标所受伤害的75% |
| 目标数量 | 最多2名：1名敌方主目标，以及1名敌方副目标或被误伤的队友 |

低理智阈值、两侧均有敌人时副目标的选择方式、周边有多名队友时误伤对象的选择方式及其他未指定参数待定。不自动将副目标选择设定为随机或由玩家指定。

## 高理智特殊技能：追击

| 项目 | 已确认设定 |
| --- | --- |
| 解锁条件 | 战士处于高理智状态 |
| 施放站位 | 战士处于己方1、2、3号位 |
| 技能效果 | 为全队赋予追击增益（buff） |
| 作用范围 | 己方全队，包含战士自己 |
| 持续时间 | 1回合 |
| 触发条件 | 持有追击增益的己方角色对敌人造成伤害时，触发追击 |
| 追击伤害 | 造成战士基础攻击伤害的50% |
| 反击联动 | 被触发的反击对敌人造成伤害时，也可以触发追击 |
| 连锁限制 | 追击不能再次触发追击 |

此技能独立于4个常规技能。高理智阈值、行动消耗、每场战斗使用次数、追击的执行者与攻击范围、伤害结算细节，以及群攻、多段伤害和持续伤害的具体触发计数规则尚未确定。未自动添加“每场战斗限用1次”或“每名角色仅触发1次”的限制。

## 已确认的设计约束

- 敌方没有肢体破坏系统。
- 钩爪技能留给射手，不作为战士技能。
- 每个角色应拥有特殊功能，使失去角色明显影响队伍的战术能力，降低角色可被轻易替代的感觉。

## 实现取值（暂定）

以下数值是实现方为跑通战斗给出的暂定值，逐条对应上文各条「待定」。数值全部集中在
`Assets/StageOne/Editor/StageOneBuild.cs` 的 `Warrior()` 一处，文档一旦确认，改那里即可。

通用口径：伤害 = 角色攻击力 × 倍率，向上取整且下限 1 点；命中率 = 角色命中（0.9）× 技能命中修正；暴击 ×1.5；
「行动消耗」在本作里固定为「消耗本回合唯一一次行动」，不计次数；形态门控沿用工程既有规则——理智 > 70 才可能抽到
技术形态，理智 < 30 才可能抽到原始形态，权重 0.2 / 0.6 / 0.2，理智 50 时固定为常态。

| 技能 | 待定项 | 暂定取值 |
| --- | --- | --- |
| 斩劈 | 伤害数值 | 攻击力 × 1.0（约 10 点） |
| 斩劈 | 前移与站位 | 前移 1 位；已在己方 1 号位时原地攻击，技能不因此禁用 |
| 猛击 | 伤害数值 | 攻击力 × 0.7（约 7 点） |
| 猛击 | 猛击自身命中率 | 沿用角色命中 0.9，未单独降低 |
| 猛击 | 目标在失衡施加前已经行动 | 不追回其本回合已完成的行动，只影响其本回合剩余的行动次数 |
| 猛击 | 与位移免疫的交互 | 「位移必中」使用独立窗口，持续施加回合与下一回合，共2回合；下回合免疫只阻止再次施加失衡，不会取消必中窗口 |
| 扩散斩击 | 主目标伤害 | 攻击力 × 0.8（约 8 点） |
| 扩散斩击 | 扩散伤害 | 主目标伤害的 50%（即攻击力 × 0.4，约 4 点） |
| 扩散斩击 | 取整与结算顺序 | 先按倍率相乘再向上取整；每名目标各自结算防御、格挡与部位 |
| 带伤强攻 | 基础伤害 | 攻击力 × 1.0 |
| 带伤强攻 | 扣血增伤公式 | 每损失 1% 最大生命 +0.5% 倍率：满血 +0，濒死上限 +50% |
| 带伤强攻 | 肢体损伤增伤层数 | 每处非完好部位记 1 层，最多 2 层；每层 +2 点固定伤害（最多 +4） |
| 带伤强攻 | 使用后受伤提升 | 本回合自身受到的伤害 +25%，回合开始时消失 |
| 扩散斩击·暴戾 | 主目标为常态 125% | 倍率 1.25，即攻击力 × 1.0（常态版本为 0.8，正好 125%） |
| 扩散斩击·暴戾 | 副目标 75% | 主目标所受伤害 × 0.75 |
| 扩散斩击·暴戾 | 两侧都有敌人时选哪一名 | 取更靠前（编号更小）的那一名 |
| 扩散斩击·暴戾 | 周边有多名队友时误伤谁 | 从战士左右相邻的队友中随机抽一名（消耗一次随机抽取） |
| 追击 | 每场战斗使用次数 | 不限次，每次施放都重新赋予全队，未加「每场 1 次」 |
| 追击 | 持续时间 | 1 回合，回合开始时统一清除 |
| 追击 | 伤害基准 | 施放时战士的基础攻击力 × 50%，不含技能倍率与暴击 |
| 追击 | 群攻/多段/持续伤害的触发计数 | 按「一次出手结算一次」计，追击落在主目标上，扩散/贯穿的旁支目标不各自触发 |
| 追击 | 追击的执行者与攻击范围 | 持有增益的每名己方角色各追加 1 次，都打同一个受击敌人 |

## 义体替换技能（已实装）

战士的两件专属义体只替换当前形态实际拥有的技能；义体随腿部或手臂断肢而销毁，技能随即恢复原版。数值与完整规则见 [义体体系实现说明.md](义体体系实现说明.md)。

| 义体 | 替换/修改 | 效果 |
| --- | --- | --- |
| 棘轮追杀腿（腿部） | 斩劈 | 伤害 +70%；可从己方 4 号位施放；使用时尽可能前移两位，沿途依次与队友换位 |
| 蒸汽碎城锤（手臂） | 猛击 → **锅炉震荡** | 对敌方 1、2 号位当前存在的每名敌人分别判定命中，造成攻击力 75% 的伤害并使其失衡；每场 2 次；用后自身受伤 +50%，至下次行动开始；耗 1 矿石 |

锅炉震荡的每个目标独立判定命中；矿石不足或次数用尽时不可用，不会回退成猛击。
