# 角色管理弹窗

运行 `Assets/Scenes/mainScene.unity`，在地图或战斗页面点击左侧任一角色框，即可打开该角色的整备弹窗。战斗角色框缩小至原来的 88%；地图角色列距左侧 8 个设计像素。

弹窗预制体：`Assets/CharacterPanelUI/Prefabs/CharacterPanel.prefab`。

左侧完整立绘区已按盾卫、战士、奶妈、枪手的顺序填入 `Assets/StageOne/Resources/StageOne/HeroArt/` 中的四张完整立绘；运行时随所选角色切换并保持原图比例。要替换图片，选中预制体根对象，在 CharacterPanelView 的 Full Body Art 四个位置按同一顺序重新指定 Sprite；重建弹窗会保留已经配置的这四张立绘引用。

点击角色后，上下两条机械连接条从屏幕最左边同时伸出，连接到窗口左侧靠上、靠下的位置，随后窗口从左向右展开。连接条的位置固定，不跟随角色栏或所选角色变化。地图和战斗共用此效果。整体展开约 0.4 秒，使用不受游戏时间缩放影响的计时；展开结束后开放窗口内操作。刷新药品和装备状态不会重复播放展开动画。

## 操作

- 四个肢体图标显示头部、躯干、手臂和腿部。重伤、断肢使用提供的破损图，安装义体后恢复正常图，并显示“义体已装载”。
- 悬停肢体显示加号，点击后在右侧选择对应部位的库存义体。完好、重伤、断肢都可装载，已装义体的部位不可替换；有手术包时优先消耗手术包，成功后手术包与义体各消耗一件；没有手术包时自由装载，失去 8 点生命（最低留 1）。补给站的安装选项不走这里，只消耗矿石且不扣生命。
- 血药恢复目标角色最大生命的 50%；理智药使用现有的“理智锁定药剂”，战斗外锁定下一场战斗，战斗中锁定本场战斗。库存不足、生命已满、已锁定或角色阵亡时显示原因。
- 点击空饰品格，从右侧仓库选择装备。每次装载后追加一个空格，多于两排时可以滚动；装备数量不限，角色限制和同一饰品不能重复装备的规则保留。
- 点击已装备饰品可查看效果或卸下，卸下后回到队伍库存。
- 点击右上角关闭、弹窗外空白处，或按 Esc 返回。

## 战斗衔接

打开弹窗会取消正在选择的技能目标，不会因为点击角色框而执行技能。敌方行动时可以查看角色，药品和装备操作需等待我方行动。战斗用药通过原有战斗引擎执行，消耗一次行动，弹窗随之关闭；地图用药后保持打开。

战斗中装载义体属于道具使用，会消耗当前角色本次行动并关闭弹窗；地图上装载立即生效。装备饰品不消耗战斗行动。战斗中装备饰品会使用现有装备效果查询，不重新触发入场效果；带开战触发条件的效果在下一场战斗生效。库存、肢体和饰品均使用本局角色的原始状态，弹窗没有另建一份角色数据。

## 维护与验证

菜单 `GameMake / Character Panel / Build And Apply` 重建弹窗并应用到主场景、StageOne、地图、战斗预览和事件预览场景。重建会覆盖该预制体的手动布局修改；布局定义在 `CharacterPanelView.BuildLayout`。

仅复制并导入用户提供的 PNG，外部原素材未改动。药瓶小标使用 UI 色块绘制，饰品以名称展示。

验证报告与运行截图位于工程上一级 `交付/角色管理弹窗`。测试覆盖四名角色对应关系、实际鼠标点击与悬停、空库存与阵亡保护、义体安装和扣库、药效和扣库、饰品扩展和限制、卸下返库、战斗用药消耗行动及新局清理。测试中发放的物品和角色状态仅存在于运行验证，不保存到正常开局。
