# 工业风事件页面

已接入主场景、StageOne 场景、地图场景及战斗预览场景，使用各场景原有的 StageOneApp 状态。进入任何非战斗房间时自动接替旧页面：事件房、增益房、补给站、电梯井、宝箱房，以及本局结束页，都按事件页的「标题 + 正文 + 选项 + 继续」结构显示。离开后返回地图。

页面内容由 `Ruin.Runtime.RoomPages` 统一生成：`RoomView.Event` 仍读 `EventScripts.Page`，其余房间由 `RoomPages` 把 `StageOneApp` 的既有命令（`ChooseBuff`、`SupplyHeal`、`SupplyCalm`、`RepairLimb`、`InstallProsthetic`、`AdvanceFloor`、`LeaveRoom`、`NewRun`）包装成同一套选项。补给站的「部位与义肢」是页面内的二级菜单（主菜单 → 队员 → 部位），只存在于事件页的视图状态里，不写入游戏存档。

直接运行 `Assets/IndustrialEventUI/Scenes/IndustrialEvent.unity` 可预览“铁门后的敲击声”。正常游戏入口仍为 `Assets/Scenes/mainScene.unity`。

## 布局与交互

- 左上：地图素材改制的横向绿色显示屏，显示事件标题、阶段和位置，保留稀疏的细扫描干扰。
- 左下：逐字显示事件正文、结果和提示，长文本可用滚轮或拖动右侧滚动条阅读。
- 右侧：通用边框制成的长条选项。当前阶段文本全部显示后，选项依次从屏幕右侧滑入，再允许点击。
- 右下：只有继续步骤时显示“继续”，结束叙述播放完后显示该页面的前进按钮（“离开”、“下到第 N 层”、“新开一局”等）。两者均使用缩小的通用边框并从右侧弹出。
- 分支、角色选择、奖励、理智条件和事件战斗继续沿用现有事件规则。
- 房间页在有选项的同时也会显示前进按钮：增益房选完增益后才能离开，补给站可以边处理边离开，其余房间直接离开。

文字默认每秒显示 38 个字，可在 IndustrialEventPage 的 CharactersPerSecond 调整。滑入耗时 0.32 秒，选项错开 0.07 秒。

显示屏当前呈现事件信息；尚未配置事件插图。预制体中保留 EventIllustration 图片位置，可供后续添加插图。

## 补给站专用布局

补给站使用左侧管理选项、右侧加大的电子屏幕；隐藏原来的事件正文框。屏幕为 1044×680，屏幕下方的“回血”和“回理智”各宽 510，间隔 24，两者总宽度与屏幕一致。保留饰品、道具、队员部位和义肢管理入口以及右下角离开按钮。恢复操作沿用实际规则，每站各一次，使用后禁用并显示已使用状态。补给站没有隐藏文字的等待时间，入口动画结束即可操作。

吉祥物图片位置：打开上述预制体，在 `Event Page / Supply Station - 补给站 / Mascot Monitor - 吉祥物显示屏 / Mascot Viewport / Mascot - 拖入吉祥物图片` 的 Image 中设置 Source Image。图片保持比例并限制在显示区内；配置图片后会自动隐藏占位文字。重建事件页面会保留已配置的吉祥物图片。

菜单 `GameMake / Event UI / Apply Supply Station Layout` 将补给站布局应用到实际入口场景。运行验证与截图位于工程上一级 `交付/补给站UI`，覆盖实际鼠标点击、生命与理智数值、重复使用限制、左侧管理入口、退出及事件页布局恢复。

补给站按钮仅首次进入当前房间时播放入场动画。回血、回理智、部位子菜单、购买、关闭商店以及返回饰品/道具管理后，现有按钮原位更新；新房间仍有首次入场动画，事件页的逐字显示与选项入场保持原有行为。

## 补给商店

左侧“商店”入口打开独立弹窗，左侧约三分之一为电子屏幕，右侧为五类商品：义体、饰品、血药、理智药、手术包。点击商品卡查看详情，点击购买后扣除本局补给并加入实际库存。商品列表可滚动；购买不会重建商品卡、重置滚动位置或重复入场。右上角关闭、点击遮罩或 Esc 均可关闭弹窗，关闭后补给站原位显示。

商店没有额外随机抽取或限购；初始定价集中在 `Assets/StageOne/Core/SupplyShop.cs`：义体 4、饰品 6、血药 2、理智药 3、手术包 3 补给。没有修改开局补给数量。补给不足时禁止购买，购买校验在游戏命令中执行，库存使用各物品的独立副本。

理智药沿用现有理智锁定药剂，效果不是直接恢复理智。手术包沿用原有“可以持有、功能待定、暂时不能使用”定义，商品描述明确展示该状态，购买不会自动使用道具。电子屏幕上方预留图片区域，跟随补给站已配置的吉祥物图片；下方展示当前商品效果、库存和价格。

商店布局维护：`SupplyShopBuilder`；运行界面：`SupplyShopView`；购买规则：`SupplyShop` 与 `StageOneSupplyShop`。验证入口 `GameMake.EventEditor.SupplyStationVerification.Run`，报告 `交付/补给站UI/validation.txt`，日志 `shop-verify.log`。
