# 第一阶段 试玩说明与验收清单

## 启动

在Unity中打开项目的 `Assets/StageOne/Scenes/StageOne.unity`，点击Play。当前画面标题为“界限之间”，是演练阶段的临时标题。

当前未提供已验证的Windows试玩构建。负责人可使用 **GameMake → Build Stage One Windows** 自行打包，构建后运行 **BetweenTheVeils.exe**，并保留其相邻数据目录。代码已经通过一次Unity编译，本清单中的运行检查尚待执行。

## 这一版可以玩什么

这是四人队伍对三名敌人的战斗演练，包含站位、角色技能、技能形态变化、濒死与战后理智反馈。战斗打到胜利或全灭，然后继续下一场，检查角色状态是否延续。

本版提前加入了**三层路线与逐步生成**：固定套路由「第1层 初始增益房 → 5 个可抽位置 → 电梯井」「第2层 补给站 → 6 个可抽位置 → 电梯井」「第3层 补给站 → 7 个可抽位置 → 首领」组成，共24个位置。可抽位置每次抽1~3个候选，选一个走过去；**走到跟前才抽下一个位置**。房间类型与候选数量由玩家理智连续决定。可抽位置上只会出现普通战斗、精英战斗、祭坛房间、事件房间与宝箱房五种，同一个位置上不会出现两张相同的房间卡片（事件房间除外）。

本版还提前加入了**开局增益与五种房间内容**：开局从坚韧（全队最大生命+8）、锋锐（全队基础攻击+2）、清明（全队初始理智+10）三选一；补给站可治疗全队、修复重伤部位、安装义肢、静养；事件房间与祭坛房间每条内容有三个选项，扩展选项按理智出现；宝箱房已经按约 8.5% 出现在路线上，但奖励内容还没定，进去什么也不给。

本版还提前加入了**肢体与义肢系统（仅己方）**：每名队员有头、躯干、手臂、腿部四个部位，各有独立血量；一次部位攻击造成重伤，两次断肢；只有执斧者的重劈与追猎者的追猎会造成部位伤害。**补给站**是唯一能处理部位的节点，可以修复重伤部位、为断肢安装义肢。义肢由精英战斗胜利掉落，F3验收工具也可直接发放。

本版不含图鉴或自动存档。**进入下一层不再自动整备生命**（整备改由每层起点的补给站承担，需要玩家自己点）；死亡角色不复活。关闭程序后演练进度结束。验收需要满血队伍时，用F3的“整备全队生命”——注意它**不会修复部位**。

## 基本操作

1. 开局先从三个全队增益中选一个，离开后从1~3个候选房间中选一个前进；点“普通战斗”进入战斗。
2. 行动区只有**当前形态的技能加一个“换位”**，点技能后再点高亮目标即可。需要调整前后排时点“换位”，再选一名相邻队员。
3. 点击任意角色，可以查看详情；敌人下方显示下一次攻击预告。
4. 无法使用的技能会在按钮上写明原因（站位不符 / 次数用尽 / 没有合法目标），不消耗行动。
5. 理智只能靠技能与房间内容改变：枪手的“军备补充”和奶妈的技能能回理智，低语者等敌人会削理智。没有防御、稳定心神、直视深渊与撤退。
6. 全队阵亡直接结束本局，没有主动撤退。队友濒死时用奶妈的“流血奶”把他治回来。
7. F1打开说明，F3打开验收工具，Esc关闭面板或取消目标选择。

## 建议验收顺序

### A 完成正常战斗

- [ ] 行动区只出现“当前形态的技能”加一个“换位”，没有防御 / 稳定心神 / 直视深渊 / 撤退这几个按钮。
- [ ] 四名角色分别是**战士 / 盾卫 / 枪手 / 奶妈**，技能名与仓库根目录的四份 `*技能记录.md` 一致。
- [ ] 点击“新开演练”，确认出现初始增益房（唯一的固定房间）。
- [ ] 选定一项增益后离开，确认回到路线页并出现1~3张候选卡片。
- [ ] 在候选里找到标着“普通战斗”的卡片走进去，完成一次从开始到胜利或全灭的流程。
- [ ] 结算后点击“继续前进”，确认回到路线页，且**层数不变、只是往前走了一格**。
- [ ] 技能有合法目标提示，站位不符时显示原因。
- [ ] 敌人行动预告、伤害、治疗与战斗记录能对照理解。

### B 检查理智区间

- [ ] F3选择“理智50”，确认“高理智/常态/低理智”三行里只有常态是100%。
- [ ] F3选择“理智15”，确认仅“低理智”有概率出现，“高理智”为0。
- [ ] F3选择“理智85”，确认仅“高理智”有概率出现，“低理智”为0。
- [ ] 注意：特殊形态不是必出。多进行几次角色行动，可观察抽取结果。
- [ ] 形态切换的是**整份技能列表**：抽到低理智时行动区只剩一个技能加换位（例如战士只剩“扩散斩击·暴戾”）；抽到高理智时，常态四个技能之外会多出那个角色的特殊技能（例如战士多出“追击”）。

### C 检查个人理智

- [ ] 点击一名存活队员查看详情，F3将该队员理智设为50，确认特殊形态概率为0。
- [ ] 点击“结束当前演练”，再点“继续前进”并在下一个战斗房间里再打一场，确认该队员的理智仍保留。

### D 检查战后反馈

- [ ] F3点击“反馈−2.5”，查看四名队员变化−20、−10、0、+10。
- [ ] 结算显示平均变化−5，乘0.5后玩家理智从50变为47.5。
- [ ] 点“继续前进”走到下一个房间，玩家理智不会再次扣除2.5。

### E 检查濒死

- [ ] F3点击“濒死演练”，确认盾卫0生命但仍存活。
- [ ] 等奶妈行动后用“流血奶”治疗盾卫，确认生命恢复后脱离濒死。
- [ ] 处于濒死时再次受到攻击或流血可能死亡；死亡队员在后续战斗中不复活。

### F 检查显示与手感

- [ ] 中文没有缺字，技能、血量、理智、房间名称与预告易于辨认。
- [ ] 缩放窗口后，按钮仍能准确点击，重要内容没有被遮挡。
- [ ] 提出需要调整的文字、布局、操作或战斗规则。

### G 检查路线生成与理智影响

- [ ] 新开一局：第1层起点是唯一的固定房间（初始增益房）；选定增益离开后出现1~3张候选卡片，卡上写明房间名与用途。
- [ ] 页面左侧列出五种房间的概率（普通战斗、精英战斗、祭坛房间、事件房间、宝箱房），五条之和为100%，且随玩家理智变化。理智50 时宝箱房显示 8.5%。
- [ ] 同一个位置上的候选不会出现两张相同的房间卡片；只有“事件房间”允许重复（两个事件并排是合法的）。
- [ ] 路线视图把已经通过的房间连成一条线，末端从主干伸出本次的候选卡片。
- [ ] 走到第1层末端的“电梯井”（F3“跳到本层末端”），点“下到第 2 层”，确认第2层从补给站开始。
- [ ] F3点“跳到首领层”再点“跳到本层末端”，确认第3层末端只有一个“首领”房间；胜利后本局结束并显示“本局通关”，首领战失败则显示“本局结束”，两者都有“新开一局”。
- [ ] 用F3的“理智 15”与“理智 85”分别新开队伍走几步，对比候选与房间分布：理智15时候选以1张为主（约2/3）、精英战斗占比更高，祭坛与宝箱基本持平（约7%~8.5%，看到就选时一局各约进入3次）；理智85时候选以3张为主（约2/3）、事件房间占比更高。在理智30与70附近做同样对比，确认**没有跳变**。
- [ ] 反复开关F1/F3返回路线页，确认当前候选的名称与顺序完全没有变化（已经展示的位置不会重抽）。
- [ ] 走完整条路线，确认三层长度分别为 1+5+1、1+6+1、1+7+1 个位置，且可抽位置上只会出现那五种房间。

### G2 检查开局增益与五种房间

- [ ] 分别选坚韧、锋锐、清明各开一局：坚韧让四名队员最大生命各+8（部位血量上限同步变大），锋锐让基础攻击各+2，清明让全队初始理智+10。
- [ ] 未选择增益时“离开增益房间”不可点。
- [ ] 用F3“进入事件房间”或“进入祭坛房间”，确认页面显示标题、正文与三个选项；不可选的选项显示为“—— 不可选 ——”且点不动。
- [ ] 选定一个选项后确认结果文字出现，离开前不能再选第二个。
- [ ] 用F3“进入补给站”做一遍 G3 与 H 的检查。
- [ ] 用F3“进入电梯井”，确认它只是过渡页：换层后全队生命没有任何变化。

### G3 检查补给站

- [ ] 让全队先掉一些血（打一场或F3“击伤”），F3“进入补给站”，确认页面列出四名队员的生命与部位。
- [ ] 点“治疗全队”，确认每名存活队员恢复各自生命上限约35%的生命，且不会超过上限；按钮随即变为“治疗已使用”且点不动。
- [ ] 确认阵亡队员不会被治疗复活。
- [ ] 点“静养”，确认玩家理智+10（封顶100），按钮随即变为“静养已使用”。
- [ ] 点“离开补给站”，确认回到路线页并继续前进（不换层）。

### G4 检查宝箱房（已上路，但奖励未定）

宝箱房按 8.5% 的基础权重**已经出现在路线上**，但它发什么奖励还没有定，所以进去什么也不给。这一节同时看它出不出得来、以及进出是否正常。

- [ ] 走两到三局，确认路线上**确实会遇到“宝箱房”**（十来个可抽位置里大约出一两次），左侧概率列表里也有它这一行。
- [ ] 走进一个宝箱房，确认页面文字说明内容待定、当前不发放任何东西；补给与义肢数量没有任何变化。
- [ ] 点“离开宝箱房”，确认回到路线页并继续前进（不换层），当前位置已正常结算，没有卡住。
- [ ] 用F3“进入宝箱房”再验一次同一页（这条不问路线，只看页面）。

### H 检查肢体与义肢

- [ ] 点击一名队员查看详情，确认右栏出现“部位损伤”，头部、躯干、手臂、腿部各有一行，状态为“完好”且血量满。
- [ ] F3点击“击伤·手臂”，确认该队员手臂变为“重伤”，右栏手臂血量下降，攻击力出现−20%的削弱；队员卡片的提示文字也标出该部位。
- [ ] F3点击“断肢·腿部”，确认腿部变为“断肢”，速度为−45%；此时技能与换位**仍然可用**（断肢不禁止行动）。
- [ ] F3点击“进入补给站”，确认页面列出四名队员与各自的四个部位。
- [ ] 对“重伤”部位点击“修复”，确认该部位恢复完好、血量回满；对“断肢”部位不应出现修复按钮，只显示缺少哪一件义肢。
- [ ] F3点击“发放全部义肢”后回到补给站，对断肢部位点击“安装 xxx”，确认部位恢复完好并显示“义肢”，页面上的持有列表中该件被扣除。
- [ ] 点“离开补给站”，确认回到路线页并继续前进。
- [ ] 完成一场含执斧者的战斗，注意行动预告在重劈回合写明“可能重创手臂”，并在战斗记录中看到部位伤害条目。
- [ ] 反复被打断的手臂部位，确认义肢会一同损毁（再次显示“断肢”），需要重新安装。
- [ ] 打一场精英战斗并取胜（F3“进入补给站”可先整备，或直接找卡片上写着“精英战斗”的房间），确认胜利后结算页显示掉落了一件义肢，并在下一次进入补给站时可以在持有列表里找到它。
- [ ] 注意：“整备全队生命”只回生命、修不好部位；修复与义肢只在补给站内进行，且补给站每层起点必定出现一次。

### I 检查四名角色的技能机制

对着四份 `*技能记录.md`（每份末尾有「实现取值（暂定）」对照表）逐条看。以下是最值得亲手验的几条：

**战士**

- [ ] “斩劈”让战士向前移动一位再攻击；已经在1号位时原地攻击，技能仍然可用。
- [ ] “猛击”命中后敌人跳过下一次行动；此后2个回合内用枪手的“拖拽射击”必定命中（位移必中覆盖施加回合与下一回合，即使敌人已被跳过行动）；被拖过一次的敌人下一回合免疫再次失衡。
- [ ] “扩散斩击”在战士2/3号位时打主目标并波及左右相邻；低理智形态“扩散斩击·暴戾”只波及一名副目标（取更靠前的那一个），主目标旁边没有敌人时有几率误伤一名相邻队友。
- [ ] “带伤强攻”每场只能用一次，使用后本人本回合受到的伤害提高；再想用第二次时按钮写明“本场技能次数已用尽”。
- [ ] 高理智特殊技能“追击”给全队挂上追击，之后每次有人打中敌人都追加一次伤害；追击只持续到本回合结束，不会追击再触发追击。

**盾卫**

- [ ] “守护”让被守护者一整回合内的每次受击都由盾卫承受，不是只挡一次；盾卫自己的回合开始时解除。
- [ ] “壁垒”提高全队防御；“格挡”给一名角色1层格挡，被攻击时完全免伤免减益并消耗掉。
- [ ] 低理智“守护·血怒”在守护队友的同时给盾卫自己挂上反击：盾卫被打或替队友挨打时反打一次，反击触发后消耗掉，守护继续。
- [ ] 高理智“全队格挡反击”每场一次，给全队各一层格挡加一次反击。

**枪手**

- [ ] “指定射击”只能打敌方2/3/4号位；“拖拽射击”只能打3/4号位，命中后40%把目标拖到1号位，原本挡在前面的敌人依次后移。
- [ ] “阻断射击”每场2次，命中后目标本回合的行动被跳过。
- [ ] “军备补充”需要点一名队友：全队精准提高，但理智只回给点选的那一名。
- [ ] 低理智“指定射击·散乱”命中率降低，主目标受125%并溅射最多两名周边敌人。
- [ ] 高理智“贯穿弹”每场3次，主目标100%、后方逐个减25%，并且**只有主目标被打断**。

**奶妈**

- [ ] “放血”造成伤害并挂两段流血；“流血奶”治疗量最高，但有50%概率给被治疗者挂上流血。
- [ ] “群体药雾”治疗全队；“驱散疗法”清除全队身上的流血。
- [ ] 低理智“流血奶·渴求”不再点目标，改为在生命未满的队友里随机治疗一名，治疗量更高、流血更重。
- [ ] 高理智“吸血扩散”攻击敌人，按实际造成的伤害治疗奶妈自己，并把一半扩散给左右相邻队友；打空（未命中）时不回血。
- [ ] 注意一条设计后果：低理智的奶妈只剩“流血奶·渴求”，而队友都满血时它没有合法目标，那一回合只能“换位”。
